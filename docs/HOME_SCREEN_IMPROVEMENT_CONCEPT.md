# 홈 화면 개선 구상

참고 이미지(차 시세 앱 + 견적 검증 앱 3종)와 현재 서비스를 바탕으로 한 **홈 화면 개선 개념**만 정리한 문서입니다.

---

## 1. 참고 이미지에서 가져올 포인트

### 1.1 첫 번째 이미지 (차 시세 앱)
- **한 줄 메인 질문**: "먼저, 내 차 시세를 알아볼까요?" → 우리는 "견적서 적정한지 확인해볼까요?"에 해당.
- **단일 입력/CTA**: 화면 중앙에 하나의 큰 행동(차량번호 입력 or 견적서 촬영)이 명확함.
- **보조 CTA**: "다음 차 찾고 계세요? 2,466대 보기"처럼 메인 외에 보조 진입로 하나.
- **여백**: 상단·중앙 여백을 넉넉히 두고, 하단 네비만 고정.

### 1.2 두 번째 이미지 – 왼쪽 (견적척척 스타일)
- **서비스명 + 상단 유틸**: 검색/알림 등은 우리는 프로필(UserMenu)만 두는 방식 유지 가능.
- **메인 카피 + 단일 CTA**: "차 수리비, 적당한지 확인해볼까요?" + **파란색 큰 버튼** "견적서 찍고 확인하기".
- **내 차 정보**: "내 차 정보 · 관리 >" + 차종·주행거리 카드 → 우리도 **내 차량 미니 요약**을 메인 CTA 바로 아래에 두는 구조와 맞음.
- **지역/수리 정보 카드**: "우리 동네 수리 정보"처럼 **보조 정보 블록**을 넣을 수 있음 (동네 인기 정비, 적정가 예시 등 – 추후 데이터 있을 때).
- **한 줄 팁**: 주황 박스 "정비소에서 '당장 안 하면 위험해요'라고 할 때…"처럼 **신뢰/이용 팁** 한 줄을 넣으면 차별화에 도움.

### 1.3 두 번째 이미지 – 가운데 (실시간 견적 분석)
- **상단 배너**: "수리 견적서, 호구 탈출 1초 전" + "12만 건 실제 데이터로 적정성 판단" → **가치 제안을 상단에 짧고 강하게** 두는 방식 참고.
- **메인 CTA**: 배너 안에 흰색 버튼 "견적서 촬영하기"로 진입점을 한 군데로.
- **2열 카드**: "검증 히스토리 5건" / "내 차 정보"를 나란히 → 우리는 **최근 검증** + **내 차량**을 비슷하게 2열 또는 리스트로 배치 가능.
- **최근 인기 정비 사례**: "투싼 겉벨트 42만원 (정상)"처럼 **검증 결과 요약 카드**를 홈에 노출하면 신뢰·재방문에 도움.

### 1.4 두 번째 이미지 – 오른쪽 (이미지 배경)
- **비주얼 히어로**: 배경 이미지 + "내 차 수리 견적, 호구 당하지 않게 확인하세요" → **감성 카피 + 한 줄 가치**를 상단에 두는 옵션.
- **2버튼 구조**: "견적서 촬영" + "검증 이력"으로 **메인/보조 행동**을 나란히.
- **내 차 정보**: "차량모델 · 주행거리" 2열 + "수정" 링크 → 우리 **내 차** 블록과 동일한 역할.
- **커뮤니티/이슈**: "최근 커뮤니티 이슈"처럼 **경량 콘텐츠**를 하단에 두는 건 추후 기능으로 고려.

## 2. 우리 서비스 홈 개선 구상 (구조안)

### 2.1 화면 위→아래 흐름 제안

| 순서 | 블록 | 구상 내용 |
|------|------|-----------|
| 1 | **상단** | 서비스명 or 로고(선택) + 프로필(우측). 필요 시 "이용약관 개정안내" 같은 공지는 최소한으로. |
| 2 | **히어로** | 한 줄 메인 카피 + 짧은 가치 문장. (예: "견적서, 적정한지 1초만에 확인해보세요" + "유사 차량 실제 데이터로 검증해드려요") |
| 3 | **메인 CTA** | **견적서 촬영하기** 하나를 가장 크게(다크/파란 카드 + 카메라 아이콘). 참고 이미지처럼 "한 가지 행동"이 보이도록. |
| 4 | **보조 CTA** | **견적 내용 직접 입력하기**는 촬영 카드 바로 아래, 절반 높이 정도로 유지. |
| 5 | **내 차 정보** | 로그인 + 차량 등록 시: "내 차 정보" 제목 + "관리 >" 또는 "수정" + 차종·연식·주행거리 한 줄. 카드 형태. |
| 6 | **최근 검증 / 검증 히스토리** | "최근 검증" 또는 "검증 히스토리" 제목 + 최근 2~3건 리스트(날짜·요약·금액·적정/확인필요 뱃지). "전체보기"는 내 차 탭으로 연결(현재처럼). |
| 7 | **보조 블록(선택)** | 아래 중 하나를 여유 있으면 추가. |
|  |  | - **한 줄 팁**: "정비소에서 '당장 안 하면 위험해요'라고 할 때, 견적서 찍어서 먼저 확인해보세요." (참고 이미지 왼쪽) |
|  |  | - **인기 정비 사례**: "최근 인기 정비 사례" 1~2건(예: 투싼 엔진오일 42만원 적정) – 데이터 확보 후 |
|  |  | - **동네/지역 정비 정보**: "우리 동네 수리 정보" – 추후 |
| 8 | **비로그인** | 메인 CTA 아래 "로그인하면 검증 이력·내 차 정보를 저장해요" 카드 유지. |

### 2.2 메인 카피 후보 (참고용)

- "견적서, 적정한지 1초만에 확인해보세요"
- "차 수리비, 적당한지 확인해볼까요?"
- "수리 견적서, 호구 탈출 1초 전" (강한 톤)
- "내 차 수리 견적, 호구 당하지 않게 확인하세요"
- 현재 유지: "OO님, 견적서를 검증해볼까요?" (로그인 시)

### 2.3 레이아웃/비주얼 방향

- **배경**: 현재처럼 **흰색/밝은 배경** 유지. (참고 오른쪽 이미지처럼 배경 사진을 쓰려면 별도 리소스 필요.)
- **메인 CTA**: 참고 이미지들처럼 **한 개가 압도적으로 크게** – 다크 또는 포인트 컬러(파란 계열) 카드 + 아이콘 + 1~2줄 설명.
- **내 차 / 최근 검증**: 카드형, 구분선으로 정리. "검증 히스토리"와 "내 차 정보"를 2열 카드로 할지, 세로 리스트로 할지는 정보량에 따라 선택.
- **하단 네비**: 현재 구조(홈 / 검증 / 내 차 / 더보기) 유지. 검증 탭이 견적서 촬영 진입점 역할을 하므로, 홈 메인 CTA와 중복되지 않게 "홈에서는 요약·동기 부여, 실제 촬영은 검증 탭 또는 이 CTA"로 정리.

### 2.4 제외하거나 나중에 할 것

- **차 시세 앱처럼 차량번호 한 개 입력만 두는 구조**: 우리는 "견적서 검증"이 메인이므로, 차량번호 입력은 내 차 등록/수정 플로우에만 둠.
- **상단 전체를 파란 배너로 채우기**: 브랜드/리소스 정해지면 검토. 당장은 상단은 여백 + 카피 + CTA 위주가 구현 부담이 적음.
- **동네 수리 정보 / 커뮤니티 이슈**: 데이터·기능 준비되면 "보조 블록" 자리에 추가.

---

## 3. 정리

- **참고 이미지**: "한 가지 메인 CTA + 내 차 정보 + 검증/이력 노출 + 선택적 팁/사례" 구조를 공통으로 활용.
- **우리 홈**:  
  - **히어로(카피 + 가치 한 줄) → 견적서 촬영(메인 CTA) → 직접 입력(보조 CTA) → 내 차 정보 → 최근 검증** 순서를 유지하되,  
  - 카피·가치 문장을 참고 이미지처럼 한 번 더 다듬고,  
  - "한 줄 팁" 또는 "최근 인기 정비 사례" 블록을 여유 있을 때 추가하는 방향으로 구상.

이 문서는 **구상만** 반영한 것이며, 실제 UI 변경은 별도 디자인/개발 단계에서 적용하면 됩니다.
