# 요구사항 정의서 재구성 매핑표

## 개요
기존 요구사항 정의서(32개 항목)를 Flow 단위로 재구성하여 20개 항목으로 정리했습니다.

## 제거된 항목 (12개)

### UI/UX 요소 (3개) → NFR_002로 통합
- REQ_UI_001: 하단 네비게이션
- REQ_UI_002: 로딩 상태 표시
- REQ_UI_003: 에러 처리

### 내부 기술 단계 (2개) → FR_AUTH_001로 통합
- REQ_DATA_002: 토큰 자동 갱신
- REQ_PERF_002: 세션 관리 최적화

### 조회 기능 (6개) → FR_HISTORY_001로 통합
- REQ_HISTORY_001: 검증 내역 목록
- REQ_HISTORY_002: 검증 내역 상세
- REQ_VEHICLE_004: 차량별 검증 이력 조회
- REQ_VERIFY_006: 검증 결과 확인
- REQ_VERIFY_007: 검증 결과 상세
- REQ_NOTIFICATION_001: 알림 목록

### 문서/정책 (2개) → 출시 체크리스트로 이동
- REQ_SETTING_003: 이용약관
- REQ_SETTING_004: 개인정보처리방침

## 통합된 항목 (1개)

### 견적서 확인 (1개) → FR_VERIFY_001/002로 통합
- REQ_VERIFY_004: 견적서 확인 → 카메라/앨범 입력 Flow에 포함

---

## 최종 통계

- **기존**: 32개 요구사항
- **재구성**: 20개 요구사항
  - Flow 요구사항: 17개 (FR_*)
  - 보안 요구사항: 1개 (SEC_*)
  - 비기능 요구사항: 2개 (NFR_*)
- **제거**: 12개 (통합 또는 출시 체크리스트로 이동)

---

## 변경 사항 요약

1. **UI 요소 제거**: UI/UX 요소는 NFR_002(공통 UX 품질 규칙)로 통합
2. **조회 기능 통합**: 모든 조회/열람 기능을 FR_HISTORY_001로 통합
3. **내부 기술 단계 통합**: 토큰 갱신, 세션 관리 최적화는 FR_AUTH_001에 흡수
4. **입력 Flow 개선**: 견적서 확인 단계를 입력 Flow에 포함
5. **문서/정책 제거**: 이용약관, 개인정보처리방침은 출시 체크리스트로 이동
6. **우선순위 재조정**: Flow 기준으로 우선순위 재평가
