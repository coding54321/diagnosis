# 전국자동차검사정비사업조합 → 블루핸즈 표준 정비표 매핑 구상

유저 입력(사설 견적 등)을 블루핸즈 표준으로 정규화할 때, **실제 업계에서 쓰는 표현**을 매핑 테이블에 넣으면 유사도만 쓰는 것보다 효과적이다. 전국조합 표준정비시간 xlsx에 나오는 **정비항목(작업명)**을 블루핸즈 표준 항목에 매핑하는 프로세스를 구상한 문서다.

---

## 1. 전국조합 xlsx 구조 요약

- **파일**: `전국자동차검사정비사업조합-표준정비시간 (1).xlsx`
- **시트**: 18개 (승용-경형, 승용-소형, … RV 등 차종/용도별)
- **첫 시트(승용-경형) 예시**:
  - **1행**: 헤더 — A1=작업명, B1=코드, C1=작업구분, D1~N1=차종(모닝 등)
  - **A열(2행~)**: **작업명**(정비항목) — “프론트 범퍼”, “후드”, “후드 록크”, “라디에이터그릴” 등
  - 같은 작업명이 여러 행에 반복(차종·옵션별 행으로 추정)
- **고유 작업명 수**: 첫 시트만 기준 약 **372개** (시트마다 일부만 다를 수 있음)

→ **매핑 소스로 쓸 “전국조합 표현” = 시트별 A열에서 추출한 고유 작업명 목록**으로 두면 된다.

---

## 2. 매핑 목표와 출력

- **목표**: 전국조합 작업명(실제 업계 표현) → `maintenance_standard_items.id`(블루핸즈 표준 ID) 1:1 매핑
- **출력**:
  - DB 테이블 `maintenance_term_mapping`: `external_term`, `standard_item_id`, `source`(전국조합), `confidence`
  - 유저 입력 정규화 시: 입력 문구 → (전처리) → `external_term` 조회 → `standard_item_id` 반환

---

## 3. 매핑 프로세스 (4단계)

### 3.1 ① 전국조합 작업명 추출

- xlsx 시트별로 **A열(작업명)**만 읽어, **고유 문자열**만 수집
- 시트가 여러 개이면: 시트별 추출 후 합치고 중복 제거 → “전국조합 고유 작업명 목록” 생성
- **산출물**: CSV 또는 JSON — `external_term` 후보 목록 (한 줄에 한 표현)

**구현 포인트**:
- xlsx는 zip+XML이므로 `xl/worksheets/sheetN.xml`에서 `<row>` → 첫 번째 `<c>` (column A) → `t="s"`일 때 `<v>`가 shared string 인덱스 → `xl/sharedStrings.xml`에서 문자열 복원
- 1행(헤더) 제외, 빈 문자열/중복 제거

### 3.2 ② 블루핸즈 후보 제안 (반자동)

각 전국조합 표현에 대해 **블루핸즈 표준 항목 후보 1~3개**를 자동 제안한다. 검수 시 선택만 하면 되도록.

**제안 방식 (우선순위)**:

1. **규칙/동의어 테이블**  
   - 미리 정의한 대응:  
     - "후드 록크" → "후드 래취 어셈블리"  
     - "후드" (단독) → "후드 판넬 어셈블리" 또는 "후드 래취 어셈블리" 등  
     - "라디에이터그릴" / "라디에이터 그릴" → "라디에이터 그릴 어셈블리"  
     - "백도어" → "테일게이트 판넬 어셈블리"  
   - 규칙이 있으면 그대로 매핑 후보 1개 반환

2. **문자열 정규화 후 정확/부분 일치**  
   - 전국조합: 공백 제거, 소문자 통일, 괄호/쉼표 정규화  
   - 블루핸즈 `work_name`도 동일 규칙으로 정규화  
   - 정규화 문자열이 **포함 관계**이거나 **완전 일치**면 해당 블루핸즈 항목을 후보로 (예: "프론트 범퍼" ⊆ "프론트 범퍼 오버홀")

3. **키워드 매칭**  
   - 전국조합 표현을 **핵심 단어**로 쪼갬 (공백, 괄호, 슬래시 기준)  
   - 블루핸즈 `work_name`에 동일 키워드가 많이 들어가면 점수 부여  
   - 상위 1~3개를 후보로 제안 (예: "헤드램프(좌측)" → "헤드 램프 어셈블리(LH)")

4. **유사도(레벤슈타인/자카드)**  
   - 위 단계에서 후보가 없거나 부족할 때만 사용  
   - 블루핸즈 전체 `work_name`과 유사도 계산 → 상위 N개 제안  
   - **자동 확정은 하지 않고**, “제안”만 하고 검수 후 매핑 테이블에 넣는 용도

**산출물**:  
- CSV 형태: `external_term`, `suggested_standard_id`, `suggested_work_name`, `match_type`(rule|exact|keyword|similarity), `score`  
- 또는 스프레드시트에서 검수자가 “선택/수정”한 뒤 최종 `external_term` → `standard_item_id`만 DB에 넣기

### 3.3 ③ 검수 및 수동 매핑

- ②에서 나온 제안 CSV/시트를 사람이 열어서:
  - 한 전국조합 표현당 **블루핸즈 표준 항목 1개**를 선택 (또는 “매핑 안 함”)
  - 1:N인 경우(좌/우, 양쪽 등): 업무 정책에 따라 “대표 1개”로 매핑하거나, 필요 시 동의어를 여러 줄로 등록(같은 standard_item_id에 여러 external_term)
- **산출물**: 확정 매핑 테이블 — `external_term`, `standard_item_id`, `source=전국조합`, `confidence=1`(수동 확정)

### 3.4 ④ DB 시드 및 런타임 사용

- **테이블**: `maintenance_term_mapping`  
  - `external_term` (text, unique 또는 unique with source)  
  - `standard_item_id` (uuid, FK → maintenance_standard_items.id)  
  - `source` (text): `'전국조합'`, `'공임나라'`, `'수동등록'` 등  
  - `confidence` (numeric, optional): 1=수동, 0.9=규칙, 0.7=유사도 등
- 확정 매핑 CSV를 INSERT하여 DB에 반영
- 유저 입력 처리 시:  
  - 입력 문자열 전처리 → `maintenance_term_mapping`에서 `external_term`으로 조회 → `standard_item_id` 사용  
  - 없으면 기존처럼 유사도/키워드로 `maintenance_standard_items`와 직접 매칭 시도, 실패 시 미매칭

## 4. 용어 대응 예시 (규칙/동의어 1차 분)

| 전국조합 (실제 표현) | 블루핸즈 표준 (작업명) | 비고 |
|----------------------|------------------------|------|
| 후드 록크 | 후드 래취 어셈블리 | 록크 ↔ 래치 |
| 후드 | 후드 판넬 어셈블리 / 후드 래취 어셈블리 | 문맥에 따라 선택 또는 대표 1개 |
| 라디에이터그릴, 라디에이터 그릴 | 라디에이터 그릴 어셈블리 | 공백/띄어쓰기 정규화 |
| 프론트 범퍼 | 프론트 범퍼 오버홀 (기능) / 프론트 범퍼 도장 (판금) | 구분 필요 시 external_term을 “프론트 범퍼 오버홀” 등으로 세분화 |
| 백도어 | 테일게이트 판넬 어셈블리 | |
| 헤드램프(좌측), 헤드램프(우측) | 헤드 램프 어셈블리(LH), (RH) | 좌/우 매핑 |
| 포그램프(좌측) | 프론트포그램프어셈블리 (LH) | |
| 프론트 휀다(좌측) | (기능) 프런트 휠 가드 어셈블리 등 | 휀더↔휠 가드 등 세부 확인 |
| 엔진오일, 엔진 오일 교환 | 엔진오일/필터/에어크리너 등 | 공임나라와 공통 표현으로도 등록 |

→ 위와 같은 **규칙/동의어**를 코드 또는 소규모 설정 테이블로 두고, ② 단계에서 “규칙 매칭”을 1순위로 두면 검수량을 줄일 수 있다.

## 5. 구현 순서 및 스크립트

1. **전국조합 작업명 추출**  
   - `python3 scripts/extract_national_association_terms.py`  
   - xlsx 모든 시트 A열에서 고유 작업명 추출 → `docs/national_association_work_terms.csv`

2. **블루핸즈 표준 목록**  
   - `public/bluehands_maintenance.csv` 또는 DB `maintenance_standard_items`에서 `category`, `no`, `work_name` 로드

3. **매핑 제안**  
   - `python3 scripts/suggest_bluehands_mapping.py`  
   - 규칙 → 정규화 포함 → 키워드 → 유사도 순으로 후보 1개 제안  
   - 출력: `docs/national_association_mapping_suggestions.csv`  
     - 컬럼: `external_term`, `suggested_category`, `suggested_no`, `suggested_work_name`, `match_type`, `score`

4. **검수**  
   - 위 CSV를 스프레드시트로 열어, 잘못된 제안 수정·빈 행 수동 매핑 후 “확정” 컬럼 또는 별도 시드용 CSV로 저장

5. **`maintenance_term_mapping` 테이블 생성 및 시드**  
   - Supabase 마이그레이션으로 테이블 생성  
   - 확정 매핑에서 `(suggested_category, suggested_no)`로 `maintenance_standard_items.id` 조회 후 INSERT

6. **유저 입력 정규화**  
   - 전처리 → `maintenance_term_mapping` 조회 → 없으면 유사도/키워드로 `maintenance_standard_items` 직접 매칭

스크립트 사용법 요약은 `scripts/README.md` 참고.
