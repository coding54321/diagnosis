# 요구사항 정의서 v3 변경 사항

## 개요
v2에서 v3로 변경하면서 NFR_002를 제거하고, 각 요구사항을 개발자 합의용으로 간결화했습니다.

---

## v2 → v3 주요 변경 사항

### 1. NFR_002 제거
- **제거된 항목**: NFR_002 공통 UX 품질 규칙
- **이유**: UI/UX 정책은 요구사항이 아니라 공통 컴포넌트/정책 문서로 분리
- **권장 위치**: UX/정책/화면설계서 또는 공통 컴포넌트 규칙 문서

### 2. 요구사항 상세 구조 개선
각 요구사항을 개발자 합의용으로 재구성:
- **입력**: 무엇을 받는가
- **처리**: 어떤 상태 변화가 일어나는가 (어떤 엔티티가 저장/수정/삭제되는가)
- **출력**: 무엇을 반환/표시하는가
- **외부 의존**: 어떤 API/스토리지를 사용하는가
- **Acceptance Criteria**: 최소 3개 (구체적인 수치 포함)

### 3. Step 기반 서술 제거
- v2의 Step1, Step2... 형식 제거
- 입력→처리→출력 중심의 간결한 서술로 변경
- 상세 시나리오는 별도 문서로 분리 권장

---

## 최종 통계

- **v2**: 20개 요구사항
- **v3**: 19개 요구사항
  - Flow 요구사항: 16개 (FR_*)
  - 보안 요구사항: 1개 (SEC_*)
  - 비기능 요구사항: 1개 (NFR_*)
- **제거**: 1개 (NFR_002 → UX/정책 문서로 이동)

---

## 요구사항 목록 (v3)

### 인증/세션 (4개)
- FR_AUTH_001: 익명 세션 생성 및 사용자 컨텍스트 확립
- FR_AUTH_002: 이메일/비밀번호 회원가입
- FR_AUTH_003: 로그인(세션 생성 포함)
- FR_AUTH_004: 로그아웃(세션 폐기)

### 차량 관리 (3개)
- FR_VEH_001: 차량 등록(Create)
- FR_VEH_002: 차량 정보 수정(Update)
- FR_VEH_003: 차량 삭제(Delete)

### 견적서 입력 및 검증 (5개)
- FR_VERIFY_001: 견적서 데이터 입력(카메라 촬영 기반)
- FR_VERIFY_002: 견적서 데이터 입력(앨범 선택 기반)
- FR_VERIFY_003: 견적서 데이터 입력(수기 입력 기반)
- FR_VERIFY_004: 검증 실행 및 결과 산출
- FR_VERIFY_005: 검증 결과 저장(이력 레코드 생성)

### 검증 이력/열람 (1개)
- FR_HISTORY_001: 저장된 검증 이력 열람(목록+상세+차량별 필터 포함)

### 공유/설정/운영 (4개)
- FR_SHARE_001: 검증 결과 공유(링크/네이티브 공유)
- FR_PROFILE_001: 프로필 관리(조회/수정)
- FR_SUPPORT_001: 고객센터 문의 제출
- FR_SETTING_001: 알림 수신 설정 변경

### 보안/비기능 (2개)
- SEC_001: 데이터 접근제어(RLS 정책 적용)
- NFR_001: 이미지 최적화(업로드 리사이즈/압축 등)

## 개선 효과

### ✅ 개발자 합의 용이성
- 각 요구사항의 **입력/처리/출력**이 명확히 정의됨
- **외부 의존**이 명시되어 개발 범위 파악이 쉬움
- **Acceptance Criteria**에 구체적 수치 포함 (정확도 80% 이상, 로딩 시간 30% 감소 등)

### ✅ 상태 변화 명확화
- 각 Flow에서 **어떤 엔티티가 저장/수정/삭제되는지** 명시
- 예: "vehicles 테이블에 INSERT (user_id, registration_number, ...)"
- 예: "verification_results 테이블에 INSERT (estimate_id, item_id, ...)"

### ✅ 외부 의존 명시
- 각 요구사항이 **어떤 API/스토리지를 사용하는지** 명시
- 예: "Supabase Auth API", "OCR API (Upstage/OpenAI Vision)", "Supabase (vehicles 테이블)"

### ✅ UI 요소 제거
- NFR_002 제거로 "UI를 요구사항으로 적은 문서" 문제 해결
- UI/UX 정책은 별도 문서로 분리 권장
