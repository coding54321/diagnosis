## 2. 계층형 IA (디렉터리 기준)

| Lv1 | Lv2 | Lv3 | 설명 |
|-----|-----|-----|------|
| **홈** | `/` | — | 진입점. 견적 촬영 CTA, 내 차량, 최근 검증, 로그인 유도 |
| **검증** | `/verify` | — | `/verify/camera`로 리다이렉트 |
| | | `/verify/camera` | 견적서 촬영. 앨범 선택·직접 입력 분기 |
| | | `/verify/album` | 앨범에서 이미지 선택 후 review로 전달 |
| | | `/verify/manual` | 견적 직접 입력 (항목·금액 등) → 완료 시 result 직행 |
| | | `/verify/review` | 위자드: 1)입력완료 2)날짜·정비소 3)차량 4)견적목록 확인 → 검증 실행 |
| | | `/verify/result` | 검증 결과 요약. 공유·저장·내 차 등록 유도 |
| | | `/verify/result/[itemId]` | 항목별 상세 (가격 범위 등) |
| | | `/verify/result/guide` | 정비사 상담 가이드 |
| **내 차** | `/vehicle` | — | 등록된 차량 정보, 검증 내역 요약 |
| | | `/vehicle/edit` | 차량 정보 등록/수정 |
| **검증 내역** | `/history` | — | 최근 검증 목록 (로그인 시) |
| | | `/history/[id]` | 검증 건별 상세 |
| **더보기** | `/settings` | — | 설정·로그인/로그아웃 |
| **인증** | `/auth/login` | — | 로그인 |
| | `/auth/signup` | — | 회원가입 |

## 3. 핵심 사용자 플로우: 견적 검증 (이미지 → 결과)

```
[홈] 또는 [하단 네비: 검증]
         │
         ▼
   ┌──────────────┐
   │ /verify      │ ─── redirect ──► /verify/camera
   └──────────────┘

   ┌──────────────────────────────────────────────────────────────────┐
   │ /verify/camera (견적서 촬영)                                       │
   │  • 촬영  or  [앨범에서 선택]  or  [직접 입력]                       │
   └──────────────────────────────────────────────────────────────────┘
         │                    │                        │
         │ 분석하기           │ 이미지 선택 후          │
         │                    │ (동일 플로우)           │
         ▼                    ▼                        ▼
   sessionStorage 저장   (이미지→review)          /verify/manual
   pendingOcr=1                                   (직접 입력 폼)
         │                                                    │
         └────────────────────┬───────────────────────────────┘
                              ▼
   ┌──────────────────────────────────────────────────────────────────┐
   │ /verify/review (위자드)                                            │
   │  Step 1: 견적서가 입력되었어요 (OCR 실행 중 → 완료 시 자동)          │
   │  Step 2: {날짜}에 {정비소} 방문했어요 (날짜·정비소 수정)             │
   │  Step 3: 어떤 차량의 견적서인가요? (차량번호·소유주 확인)            │
   │  Step 4: 견적 목록 확인·수정 → [견적 검증하기]                       │
   └──────────────────────────────────────────────────────────────────┘
                              │
                              ▼
   ┌──────────────────────────────────────────────────────────────────┐
   │ /verify/result                                                    │
   │  • 검증 결과 요약 (적정/검토권장 등)                                │
   │  • [공유] [내 검증 내역에 저장] [내 차 등록] [로그인]                │
   │  • 항목 클릭 → /verify/result/[itemId]                             │
   │  • 가이드 → /verify/result/guide                                   │
   └──────────────────────────────────────────────────────────────────┘
```

## 4. 네비게이션 매트릭스 (어디서 어디로)

| 출발 | 도착 가능 경로 |
|------|----------------|
| **홈** | /verify/camera, /vehicle, /history, /history/[id], /auth/login |
| **검증(카메라)** | /verify/review (분석하기), /verify/manual (직접 입력), 뒤로 |
| **검증(리뷰)** | /verify/result (검증하기), /verify/camera (뒤로·에러 시), /verify/manual (에러 시) |
| **검증(결과)** | /verify/result/[itemId], /verify/result/guide, /vehicle, /auth/login, (공유 외부) |
| **내 차** | /vehicle/edit, /history, /history/[id], /auth/login |
| **검증 내역** | /history/[id] |
| **더보기** | /, /auth/login |
| **하단 네비** | /, /verify/camera, /vehicle, /settings (항상 노출, 일부 화면에서 숨김) |

## 6. Mermaid 다이어그램 (플로우)

```mermaid
flowchart TB
    subgraph 진입
        A[홈 /] --> B[검증 /verify/camera]
        A --> C[내 차 /vehicle]
        A --> D[검증 내역 /history]
    end

    subgraph 견적_입력
        B --> E[촬영 or 앨범 or 직접입력]
        E --> F[분석하기 → review]
        E --> G[직접 입력 /manual]
        G --> H[저장 → result]
    end

    subgraph 검증_위자드
        F --> I[Review Step1: OCR]
        I --> J[Step2: 날짜·정비소]
        J --> K[Step3: 차량]
        K --> L[Step4: 견적목록]
        L --> M[견적 검증하기]
    end

    subgraph 결과
        M --> N[결과 /result]
        H --> N
        N --> O[항목상세 /result/itemId]

    end

    subgraph 부가
        C --> Q[/vehicle/edit]
        D --> R[/history/id]
    end
```
