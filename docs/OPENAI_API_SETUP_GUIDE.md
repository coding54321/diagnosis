# OpenAI API 키 설정 및 테스트 가이드

OpenAI API 키를 설정한 후 해야 할 작업 단계를 정리한 문서입니다.

---

## 1. 환경 변수 설정

### 1.1 `.env.local` 파일에 API 키 추가

프로젝트 루트의 `.env.local` 파일에 다음을 추가:

```bash
OPENAI_API_KEY=sk-your-api-key-here
```

**주의사항:**
- `.env.local`은 `.gitignore`에 포함되어 있어야 합니다 (이미 포함되어 있을 것입니다)
- API 키는 절대 공개 저장소에 커밋하지 마세요
- Vercel 등 배포 환경에도 환경 변수로 설정해야 합니다

---

## 2. 개발 서버 재시작

환경 변수를 변경했으므로 개발 서버를 재시작해야 합니다:

```bash
# 현재 실행 중인 서버 중지 (Ctrl+C)
# 그 다음 다시 시작
npm run dev
```

---

## 3. 기본 테스트 (Phase 1 검증)

### 3.1 테스트 시나리오

1. **견적서 촬영 화면 진입**
   - `/verify/camera` 접속
   - 실제 견적서 이미지 촬영 또는 앨범에서 선택

2. **"분석하기" 버튼 클릭**
   - 로딩 상태 확인 ("분석 중..." 표시)
   - OpenAI API 호출 (약 2-5초 소요)

3. **OCR 결과 확인**
   - 성공 시: Review 페이지(`/verify/review`)로 자동 이동
   - Review 페이지에서 OCR 결과가 자동으로 채워졌는지 확인:
     - 정비소명
     - 의뢰일자
     - 정비 항목 (이름, 부품비, 공임비)
     - 차량번호 (있는 경우)
     - 총 금액, VAT 정보

4. **에러 케이스 테스트**
   - 견적서가 아닌 이미지 업로드 → "견적서가 아닌 것으로 보입니다" 안내
   - 흐릿한 이미지 → "이미지 품질이 낮습니다" 안내

### 3.2 확인할 사항

- [ ] OCR 결과가 Review 페이지에 올바르게 표시되는가?
- [ ] 부품비/공임비가 정확히 추출되는가?
- [ ] 항목명이 정확한가?
- [ ] 카테고리가 올바르게 분류되는가? (백엔드에서만 확인, UI에는 표시 안 함)
- [ ] 에러 케이스가 적절히 처리되는가?

## 4. 문제 해결

### 4.1 API 키 오류

**증상:** "OpenAI API 키가 설정되지 않았습니다" 오류

**해결:**
1. `.env.local` 파일 확인
2. `OPENAI_API_KEY=sk-...` 형식이 올바른지 확인
3. 개발 서버 재시작

### 4.2 API 호출 실패

**증상:** "OCR 처리 중 오류가 발생했습니다" 오류

**확인 사항:**
1. API 키가 유효한지 확인 (OpenAI 대시보드에서 확인)
2. API 사용량/크레딧 확인
3. 네트워크 연결 확인
4. 브라우저 콘솔에서 상세 오류 메시지 확인

### 4.3 OCR 결과가 부정확한 경우

**확인:**
1. 이미지 품질 확인 (해상도, 명도, 대비)
2. OpenAI Vision API 응답 확인 (브라우저 개발자 도구 → Network 탭)
3. 프롬프트 개선 필요 여부 검토

**개선 방법:**
- `lib/openai/vision.ts`의 프롬프트 수정
- 모델 변경 (`gpt-4o-mini` → `gpt-4o`)

## 6. 배포 시 주의사항

### Vercel 배포 시

1. Vercel 대시보드 → 프로젝트 → Settings → Environment Variables
2. `OPENAI_API_KEY` 추가
3. 재배포

### 비용 관리

- `gpt-4o-mini` 사용 권장 (비용 절감)
- 필요시 `gpt-4o`로 업그레이드 (정확도 향상)
- API 사용량 모니터링 (OpenAI 대시보드)
