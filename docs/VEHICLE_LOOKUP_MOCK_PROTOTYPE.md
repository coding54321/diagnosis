# 차량번호 조회 목업 (프로토타입)

API 미연동 시에도 차량번호 입력 → 차량 정보 조회가 동작하도록 `vehicle_lookup_mock` 테이블에 20대 분량 목업 데이터를 넣어 두었습니다.

## 1. 사용 방법

- **Server Action**: `fetchVehicleByRegistrationNumber(registrationNumber: string)`  
  - `lib/supabase/actions.ts`  
  - 클라이언트에서 `차량등록번호(번호판)` 문자열만 넘기면, 공백/하이픈 제거 후 `vehicle_lookup_mock`에서 조회해 `{ manufacturer, model, variant, year, mileage, fuelType }` 형태로 반환합니다. 목업 데이터에는 주행거리(mileage, km)도 넣어 두었습니다.
- **쿼리**: `getVehicleLookupByRegistrationNumber(registrationNumber)`  
  - `lib/supabase/queries.ts`  
  - 서버 전용. 원본 행(`raw`)까지 필요할 때 사용합니다.

## 3. DB 구조

- **테이블**: `public.vehicle_lookup_mock`
- **조회 키**: `registration_number` (unique)
- **컬럼**: 공통항목(제원관리번호, 차종명, 차명, 모델연도, 사용연료명, 차대번호 등) + **주행거리(mileage, km)**. 스키마는 마이그레이션 참고.

## 4. 실제 API 연동 시

자동차종합정보 첨부형API 연동 후에는 `getVehicleLookupByRegistrationNumber`(또는 별도 함수)에서 먼저 API를 호출하고, 실패/미등록 시에만 `vehicle_lookup_mock`을 fallback으로 조회하도록 바꾸면 됩니다.
