## 차량 관리

### FR_VEH_001: 차량 등록(Create)
**상태 변화:** `vehicles` 테이블에 새 레코드 INSERT
- 필드: `user_id`, `registration_number`, `manufacturer`, `model`, `variant`, `year`, `mileage`, `fuel_type`, `nickname`

### FR_VEH_002: 차량 정보 수정(Update)
**상태 변화:** `vehicles` 테이블의 기존 레코드 UPDATE
- 수정 필드: `mileage`, `nickname`
- 조건: `id = 차량ID AND user_id = 현재사용자UUID`

### FR_VEH_003: 차량 삭제(Delete)
**상태 변화:** `vehicles` 테이블의 기존 레코드 DELETE
- 조건: `id = 차량ID AND user_id = 현재사용자UUID`

## 견적서 입력 및 검증

### FR_VERIFY_001: 견적서 데이터 입력(카메라 촬영 기반)
**상태 변화:** 
- `vehicles` 테이블에 새 레코드 INSERT (차량 정보)
- `estimates` 테이블에 새 레코드 INSERT (견적서 정보)
- `estimate_items` 테이블에 새 레코드들 INSERT (정비 항목들)

### FR_VERIFY_002: 견적서 데이터 입력(앨범 선택 기반)
**상태 변화:** 
- `vehicles` 테이블에 새 레코드 INSERT (차량 정보)
- `estimates` 테이블에 새 레코드 INSERT (견적서 정보)
- `estimate_items` 테이블에 새 레코드들 INSERT (정비 항목들)

### FR_VERIFY_003: 견적서 데이터 입력(수기 입력 기반)
**상태 변화:** 
- `vehicles` 테이블에 새 레코드 INSERT (차량 정보)
- `estimates` 테이블에 새 레코드 INSERT (견적서 정보)
- `estimate_items` 테이블에 새 레코드들 INSERT (정비 항목들)

### FR_VERIFY_004: 검증 실행 및 결과 저장(결과 산출 + 이력 생성 포함)
**상태 변화:** 
- `verification_results` 테이블에 새 레코드들 INSERT (항목별 검증 결과)
- `verification_history` 테이블에 새 레코드 INSERT (검증 이력)
- 필드: `user_id`, `estimate_id`, `date`, `items`, `total_amount`, `status`, `shop_name`, `vehicle_label`
