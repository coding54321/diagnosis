# 정비표 표준 분석 및 DB 설계 제언

---

## 기획 기준 정리 (통합 기준)

**본 프로덕트에서는 블루핸즈에서 제공하는 표준정비표(`bluehands_maintenance.csv`)를 통합 기준으로 활용한다.**

### 배경

- **블루핸즈 / 오토큐 / 하이테크센터**에서는 HMG 그룹 자회사 **(주)지아이티(GIT)**에서 개발한 **현대 GDS-Smart / KIA KDS 2.0**을 활용하여 진단을 수행한다. GIT에서 개발한 하드웨어를 차량에 결착하면 태블릿 소프트웨어를 통해 **DTC**(Diagnostic Trouble Code)를 확인할 수 있고, 이를 기반으로 진단/정비 위치와 항목이 결정된다.
- **HYUNDAI GSW**(Global Service Way), **KIA GSW**를 운영하여 각 차종별 정비지침서와 DTC 지침서를 제공하며, 표준 작업항목에 대한 기준표가 있고 실제 정비소에서도 이 기준표를 기반으로 견적서를 제공하고 있다.
- 따라서 **현대자동차·기아자동차·제네시스 차종**의 경우 현대자동차/KIA/GENESIS의 기존 정비 데이터를 통일된 형식으로 제공할 수 있다는 가정 하에, **본 프로덕트는 블루핸즈 표준정비표를 기준으로 기획·통합을 진행**한다.

### 정리

| 항목 | 내용 |
|------|------|
| **통합 기준** | 블루핸즈 표준정비표 (`bluehands_maintenance.csv`) |
| **적용 범위** | 현대·기아·제네시스 차종, 블루핸즈/오토큐/하이테크센터 정비 체계 |
| **다른 출처** | 전국조합·공임나라·사설 견적 등은 위 블루핸즈 기준에 **매핑·정규화**하여 통합 |

## 1. 데이터 소스 요약

### 1.1 블루핸즈 표준 정비표 (`bluehands_maintenance.csv`)

| 항목 | 내용 |
|------|------|
| **구조** | `구분` \| `NO` \| `작업명` \| **차종별 표준공임(시간)** |
| **행 수** | 약 161개 (기능정비 110 + 판금도장 50) |
| **차종** | 현대·기아 중심 (엑센트, 아반떼, 쏘나타, 그랜저, G70/G80, EQ900, 코나, 투싼, 싼타페, 포터 등) |
| **단위** | **시간**(예: 0.3, 1.2) |
| **작업명 특성** | 정비/부품 용어가 구체적·영문 혼용 (예: 워터펌프어셈블리, 리어쇼크업소버, 스트러트 인슐레이터) |

- **구분**: 기능정비 / 판금도장
- **작업명**: 한 항목당 하나의 표준 작업(좌/우, 양쪽 등 구분 있음)
- **차종 컬럼**: RB, AD, PD, LF, IG 등 **프로젝트 코드**로 되어 있어, 별도 차종 마스터와 매핑 필요

### 1.2 전국자동차검사정비사업조합 표준정비시간 (`전국자동차검사정비사업조합-표준정비시간 (1).xlsx`)

| 항목 | 내용 |
|------|------|
| **구조** | **차종 × 부품/작업** 매트릭스 (행/열 중 하나가 차종, 하나가 작업) |
| **규모** | 약 657행 × 14열, shared string 4,000개 이상 |
| **차종** | **제조사 무관** (비스토, 티코, 마티즈, 아토즈 등 — GM/쉐보레·기타 국산 포함) |
| **작업/부품명** | 후드, 헤드램프, 리어 도어, 루프패널, 백도어, 크러쉬패드, 안전벨트 등 **일반/한글 위주** |

- **용어**: 블루핸즈와 다름 (예: 후드 록크 vs 후드 래치, 백도어 vs 테일게이트, 카울그릴 vs 라디에이터 그릴)
- **역할**: 전국 사설정비업체 공통 참조용 **표준 시간**으로 추정 (단위는 시트 내 숫자 확인 필요)

### 1.3 공임나라 (`gongimnara/gongim_domestic.md`)

- **작업 단위**: 서비스 항목별 **공임비(원)** + 소요시간(분)
- **차종/제조사**: 현대, 기아, 제네시스, 쉐보레, 르노, 쌍용 등 **예외 규정이 많음**
- **표현**: "엔진오일교환", "미션오일", "브레이크패드" 등 **고객/업체가 쓰는 서비스명**에 가깝고, 블루핸즈의 세부 부품명과는 레벨이 다름

## 2. 공통점과 차이점

### 2.1 공통점

- **표준 공임/시간**을 정의한다는 목적이 같음.
- **작업 단위**가 존재함 (블루핸즈: 작업명+차종별 시간, 전국조합: 부품/작업+차종별 시간, 공임나라: 서비스명+공임/시간).
- **차종**이 모두 변수로 작용함 (블루핸즈·전국조합은 차종별 시간, 공임나라는 차종별 예외).
- **기능정비/부품교환**과 **판금·도장** 계열을 모두 다룸 (블루핸즈는 구분이 명시적, 전국조합은 부품명으로 구분 가능).

### 2.2 차이점

| 구분 | 블루핸즈 | 전국자동차검사정비사업조합 |
|------|----------|----------------------------|
| **용어 체계** | 현대/기아 정비 매뉴얼·영문 혼용 (어셈블리, LH/RH, 인슐레이터 등) | 한글·일반 용어 (후드, 백도어, 휀다패널 등) |
| **차종 범위** | 현대·기아·제네시스 | 제조사 무관(국산·수입 포함 가능성) |
| **단위** | 시간 | 시간(추정, 시트 확인 필요) |
| **세분화 수준** | 한 작업당 하나의 항목, 좌/우/양쪽 구분 명시 | 부품/패널 단위로 세분화된 항목 다수 |
| **정비 vs 판금** | 기능정비 / 판금도장 구분 컬럼 있음 | 시트 구조상 부품명으로만 구분 가능 |
| **메인 사용처** | 블루핸즈 내부·현대/KIA 시스템 연동 | 전국 사설정비업체 견적·표준시간 참조 |

### 2.3 용어 매핑 예시 (블루핸즈 ↔ 전국조합/일반)

- **후드**  
  - 블루핸즈: 후드 래취 어셈블리, 후드 판넬 어셈블리  
  - 전국조합: 후드 록크, 후드 케이블, 후드 인슐레이션  
- **리어 도어**  
  - 블루핸즈: 리어도어판넬어셈블리(LH/RH)  
  - 전국조합: 리어 도어(좌/우, 전동)  
- **그릴**  
  - 블루핸즈: 라디에이터 그릴 어셈블리  
  - 전국조합: 카울그릴, 헤드램프 가니쉬  
- **엔진오일**  
  - 블루핸즈: 엔진오일/필터, 엔진오일/필터/에어크리너  
  - 공임나라: 엔진오일교환 (공임비+시간)  
  - 사설 견적: "오일교환", "E/G OIL" 등 다양

→ **같은 작업이라도 출처에 따라 명칭이 달라서, “하나의 표준 목록”으로 정규화하려면 매핑 테이블이 필수**입니다.

## 3. 제언: 어떤 데이터를 메인으로 삼을지

### 3.1 블루핸즈를 메인 DB 구조로 두는 것을 권장

이유는 아래와 같습니다.

1. **현대/KIA 입장**  
   - 이미 블루핸즈 표를 쓰고 있으므로, **블루핸즈 항목·코드가 메인**이면 제조사/블루핸즈 쪽 DB·시스템에 그대로 편입하기 쉽습니다.
2. **정규화 단위가 명확함**  
   - `구분 + NO + 작업명`으로 **한 줄에 한 표준 작업**이 정의되어 있어, “견적 한 줄”을 “표준 정비 항목 한 개”에 대응시키기 좋습니다.
3. **차종 코드**  
   - RB, AD, LF 등 **프로젝트 코드**를 쓰면, 이후에 차종 마스터와만 매핑하면 되어 확장이 단순합니다.
4. **포괄성은 매핑으로 보완**  
   - 전국조합·공임나라·사설 업체는 **용어가 다르지만 작업 종류는 겹침**이 많습니다.  
   - “다른 출처의 한 항목” → “블루핸즈 표준 항목(또는 신규 표준 코드)”로 **매핑 테이블**을 두면, 블루핸즈 메인을 유지하면서도 전국/사설 견적을 흡수할 수 있습니다.

따라서 **“우리 서비스 DB의 공통 정비 목록 = 블루핸즈 표준 정비표를 기반으로 한 마스터”**로 두고,  
전국조합·공임나라·스캔된 견적 문구는 **이 마스터로 정규화(매칭)**하는 구조를 추천합니다.

### 3.2 전국자동차검사정비사업조합 표의 활용

- **역할**:  
  - **매핑 소스**로 사용 (전국조합 부품명 ↔ 블루핸즈 작업명 매핑).  
  - 블루핸즈에 없는 **차종/부품**이 있으면, 전국조합 항목을 “보조 표준 코드”로 두거나, 나중에 블루핸즈 측에 제안할 후보로 활용.
- **포괄성**  
  - 사설 업체가 “전국조합 표준시간”을 참고해 견적을 쓸 수 있으므로, **스캔된 견적 문구가 전국조합 용어에 가까울 경우** 매칭 정확도를 높이는 데 유리합니다.
- **저장 방식**  
  - 블루핸즈 메인 테이블에는 “표준 정비 항목 ID + 차종별 시간”만 두고,  
  - 전국조합 데이터는 **별도 테이블(또는 매핑용 뷰)**로 두고 “블루핸즈 표준 ID”와만 연결해 두는 방식이 좋습니다.

### 3.3 공임나라 데이터의 활용

- **역할**:  
  - “엔진오일교환”, “미션오일” 같은 **서비스명 → 블루핸즈 작업명** 매핑용.  
  - 공임비는 **비교/검증용 참고치**로만 사용(DB 구조의 주축은 “표준 정비 목록 + 시간” 유지).
- **차종/예외**  
  - 공임나라의 차종·예외 규정은 **가격/시간 참고**나 “이 차종은 이 표준 항목” 연결에 활용 가능합니다.

## 4. DB 설계 방향 (요약)

### 4.1 메인: 블루핸즈 기반 표준 정비 마스터

- **표준 정비 항목 테이블**  
  - `구분`(기능정비/판금도장), `NO`, `작업명`, 필요 시 `표준코드`(자체 부여).  
  - 블루핸즈 CSV를 이 테이블로 이관하면 됨.
- **차종 마스터**  
  - 블루핸즈 프로젝트 코드(RB, AD, LF 등) ↔ 차종명/연식 등.
- **차종별 표준 시간**  
  - `표준정비항목ID × 차종코드 → 표준공임시간(시간)`  
  - 블루핸즈 CSV의 차종 컬럼을 정규화한 형태.

### 4.2 정규화/매칭용

- **동의어/매핑 테이블**  
  - “외부 표기”(전국조합 부품명, 공임나라 서비스명, 사설 견적에서 자주 나오는 문구) → `표준정비항목ID`  
  - 예: `["오일교환","엔진오일교환","E/G OIL","엔진오일"] → 엔진오일/필터/에어크리너(블루핸즈 NO 58)`  
  - OCR/스캔 결과는 이 “외부 표기”와 매칭(유사도 또는 키워드) 후 표준 ID로 정규화.
- **전국조합 데이터**  
  - 전국조합 시트를 파싱해 “전국조합 부품명 + 차종 → 시간” 테이블을 만들고,  
  - “전국조합 부품명”을 위 동의어 테이블에 넣어 **블루핸즈 표준 ID**와 연결.

### 4.3 유저 견적 비교 플로우와의 연결

1. **유저 견적 이미지 → OCR/스캔**  
   - 텍스트 라인 단위로 “작업 설명 + 금액(또는 시간)” 추출.
2. **각 라인을 표준 항목으로 매칭**  
   - 동의어/매핑 테이블 + (선택) 전국조합/공임나라 용어로 **표준정비항목ID** 결정.  
   - 매칭 실패 시: “미매칭”으로 보관하고, 나중에 매핑 후보로 활용하거나 수동 매핑.
3. **정규화된 견적**  
   - `(견적ID, 표준정비항목ID, 차종, 공임/부품비, 출처: 블루핸즈/공임나라/사설 등)` 형태로 저장.
4. **비교**  
   - “같은 표준정비항목ID + 같은 차종”끼리 모아서 금액/시간 분포를 보여주면,  
   - 블루핸즈 표준 시간과도 비교 가능하고, 현대/KIA 쪽에서도 동일한 표준 코드로 집계 가능합니다.

## 4.5 사설업체 정비항목을 현대/KIA(블루핸즈) 기준으로 정규화하는 방법

**고민**: 사설업체 견적서에 적힌 정비항목(공임나라·전국조합·업체 자체 표현)을 어떻게 블루핸즈 표준 항목으로 맞출 것인가?

### 1) 전체 흐름

```
사설 견적 텍스트(OCR 등)
    → [정규화 전처리] → [매칭] → 표준정비항목ID(블루핸즈)
         ↑                    ↑
    공백/띄어쓰기 정리      매핑 테이블 + 키워드/유사도
```

- **입력**: “엔진오일 교환”, “오일교환”, “E/G OIL 교체”, “후드락 수리” 등 **사설에서 쓰는 표현**
- **출력**: 블루핸즈 표준정비항목 ID (또는 “미매칭” 후보)

### 2) 매핑 테이블 설계 (핵심)

**테이블: `maintenance_term_mapping` (또는 `정비항목_동의어_매핑`)**

| 컬럼 | 설명 |
|------|------|
| `external_term` | 사설/공임나라/전국조합 등에서 쓰는 **표현**(정규화된 문자열) |
| `standard_item_id` | 블루핸즈 표준 정비 항목 ID (FK) |
| `source` | 출처(공임나라, 전국조합, 수동등록, 유저제보 등) |
| `confidence` | 매핑 신뢰도(수동=1, 규칙=0.9, 유사도=0.7 등) — 선택 |

- **정확 매칭**: OCR/파싱 결과를 정규화(소문자·공백 통일, 오타 보정 등)한 뒤 `external_term`으로 조회 → `standard_item_id` 반환.
- **1:N 허용**: 하나의 외부 표현이 블루핸즈 항목 하나에만 연결되도록 관리(같은 작업이 좌/우·양쪽으로 나뉘면, 규칙으로 보정하거나 대표 항목 하나로 매핑).

### 3) 매핑 데이터 어디서 채울지

| 순서 | 데이터 소스 | 활용 방법 |
|------|-------------|-----------|
| 1 | **공임나라** | “엔진오일교환”, “미션오일”, “브레이크패드 교체” 등 **서비스명**을 블루핸즈 작업명과 1:1 매핑해 `external_term`으로 등록. |
| 2 | **전국조합 표준정비시간** | 부품/작업명(후드 록크, 리어 도어, 카울그릴 등)을 블루핸즈 항목과 매핑. 전국조합 용어 = 사설에서 자주 쓰는 용어와 비슷할 가능성이 큼. |
| 3 | **실제 견적 샘플** | 유저 견적·테스트 수집 문구 중 자주 나오는 표현을 추출해 “미매칭” 목록으로 쌓고, 수동/반자동으로 표준 항목에 매핑 후 `external_term` 추가. |
| 4 | **업체별 표현** | 특정 프랜차이즈·체인에서 반복되는 표현이 있으면 별도로 수집해 동일하게 매핑 테이블에 넣기. |

→ **1·2로 기본 커버리지를 만들고, 3·4로 서비스 운영하면서 매핑을 계속 보강**하는 구조가 현실적입니다.

### 4) 매칭 전략 (단계별)

| 단계 | 방법 | 설명 |
|------|------|------|
| 1 | **정확 매칭** | 전처리된 문구가 `external_term`과 **완전 일치**하면 해당 `standard_item_id` 사용. |
| 2 | **부분/키워드 매칭** | “엔진오일 + 교환”, “브레이크 + 패드” 등 **핵심 키워드**로 블루핸즈 작업명 또는 `external_term`과 매칭. 전국조합·공임나라에서 쓰는 단어를 키워드로 정의해 두면 유리. |
| 3 | **유사도 매칭** | 문자열 유사도(레벤슈타인, 자카드) 또는 임베딩 유사도로 “가장 가까운” 표준 항목 후보 1~3개 추천. **자동 적용은 신중히**(검수 후 매핑 테이블에 넣는 용도로 쓰는 것을 권장). |
| 4 | **미매칭 처리** | 위 단계에서도 매칭 안 되면 “미매칭”으로 저장하고, 목록을 주기적으로 검토해 수동 매핑 또는 새 동의어 등록. |

→ **1 → 2 → 3** 순으로 시도하고, 실패 시 미매칭으로 두는 플로우가 관리하기 좋습니다.

### 5) 전처리 규칙 (단순하지만 효과적)

- 공백·줄바꿈 정리, 전/후 불필요 문자 제거.
- “엔진오일” / “엔진 오일” / “E/G OIL” 같이 **동일 의미로 쓸 수 있는 표현**을 하나의 정규형으로 치환한 뒤 매칭(또는 각각을 `external_term`으로 등록).
- 숫자·단위(개, 조, 세트 등)는 매칭 시 제거하거나 별도 필드로만 파싱.

### 6) 운영 정리

- **미매칭 로그**를 남기고, 자주 나오는 문구부터 매핑 테이블에 추가하면 점점 사설 표현 커버리지가 늘어남.
- 전국조합·공임나라 용어를 **1차 매핑**으로 넣어 두면, 같은 용어를 쓰는 사설 견적은 자동으로 블루핸즈 기준으로 정규화됨.
- 현대/KIA 입장에서는 “어떤 표준 항목으로 집계되었는지”만 보면 되므로, **내부적으로는 항상 표준정비항목ID만 사용**하면 됨.

**요약**: **매핑 테이블(사설/공임/전국조합 표현 → 블루핸즈 표준 ID)**을 만들고, 공임나라·전국조합·실견적 샘플로 채운 뒤, 매칭은 “정확 → 키워드 → 유사도” 순으로 적용하고, 미매칭은 수집·검토해 지속 보강하는 방식이 좋습니다.

## 5. 정리 및 다음 단계 제언

- **공통 정비 목록 표준**  
  - **블루핸즈 표를 메인**으로 하고,  
  - **전국자동차검사정비사업조합**은 “용어 매핑 + 포괄성 보강”용,  
  - **공임나라**는 “서비스명 매핑 + 공임 참고”용으로 두는 구성이 적절합니다.
- **효과**  
  - 한쪽은 “블루핸즈/현대·KIA 친화”, 다른 한쪽은 “전국·사설 견적 포괄”을 동시에 만족시키고,  
  - 유저 견적을 **하나의 표준 목록**으로 정규화해 비교·분석할 수 있습니다.
- **추가로 하면 좋은 작업**  
  1. 블루핸즈 CSV를 DB 마이그레이션으로 **표준 정비 항목 + 차종별 시간** 테이블에 반영.  
  2. 전국조합 xlsx를 파싱해 **부품명·차종·시간** 테이블 생성 후, 블루핸즈 작업명과 **매핑 테이블** 1차 작성(수동/반자동).  
  3. 공임나라 서비스명(엔진오일, 미션오일 등)을 표준 항목과 연결하는 **동의어 행** 추가.  
  4. OCR 결과와 매칭할 때 사용할 **유사도/키워드 규칙** 설계 및 매칭 API 설계.

이렇게 하면 “블루핸즈 메인 + 전국/공임 매핑”으로 포괄성과 현대/KIA 연동을 모두 만족시키는 구조를 만들 수 있습니다.
