# 자동차종합정보 첨부형API 활용 정보 목록

자동차종합정보 첨부형API에서 제공받을 수 있는 정보 목록과, 본 서비스(자동차 정비 견적 검증)에서 실제로 활용할 항목을 정리한 문서입니다.

---

## 1. API 제공 정보 분류

API 응답은 대략 다음 영역으로 구분됩니다.

| 분류 | 설명 |
|------|------|
| 자동차기본 | 차량 식별·등록·소유 관련 기본 정보 |
| 자동차제원1·2 | 차량 제원(중량, 치수, 엔진, 연료 등) |
| 정비이력 | 정비 접수·완료·정비사업자·작업내용 등 |
| 성능점검1·2 | 성능점검·검사 유효기간·주행거리 등 |

## 3. 본 서비스에서 실제 활용할 항목

견적 검증 서비스에서는 아래 항목만 추출하여 사용하며, 나머지 항목은 저장·표시하지 않습니다.

| 활용 목적 | API 항목 (예시) | 서비스 내 저장·표시 |
|-----------|-----------------|---------------------|
| 차량 식별·조건 매칭 | 차종명, 차명, 형식명, 제작자명, 모델연도(연식), 사용연료명, 차종유형명 등 | 제조사(manufacturer), 차종(model), 연식(year), 연료(fuelType) 등으로 매핑 |
| 견적 검증 시 “유사 차량” 기준 | 위 + 주행거리(가능한 경우) | 동일·유사 조건 클러스터링에 사용 |
| 차량 정보 자동 입력 UX | 최초등록일, 차종명, 차명, 사용연료명 등 | 앱 “내 차 정보” 폼 자동 채움 |
| 주행거리 (선택) | 정비차량_주행거리, 성능점검_주행거리, 주행거리 | 있으면 표시·검증 조건에 반영, 없으면 사용자 직접 입력 유도 |

개인식별·민감 정보(차대번호, 소유주, 사용본거지, 정비사업자 개별 식별 등)는 조회 후 저장하지 않고, 비식별화된 차량 속성만 저장·활용합니다.
