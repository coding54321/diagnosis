# 프로덕트 와이어프레임 명세 (전체 페이지·상태별)

Figma에 와이어프레임을 그릴 때 참고하는 명세입니다.  
**페이지별·상태별**로 구분해 두었으니, 프레임 이름은 `페이지명 / 상태명` 형태로 붙이면 됩니다.

---

## 1. 공통 레이아웃

### 1.1 메인 영역 (하단 네비게이션 있음)
- **경로**: `(main)` 레이아웃 하위 모든 페이지
- **구성**:
  - 상단: safe-area-inset-top 반영, 콘텐츠별 헤더(뒤로가기 또는 프로필만 등)
  - 본문: Container (max-width), 세로 스크롤
  - 하단 고정: **하단 네비** 4개 — 홈 | 검증(카메라) | 내 차 | 더보기

### 1.2 인증 영역 (하단 네비 없음)
- **경로**: `/auth/*`
- **구성**: 상단 뒤로가기만, 본문만 (하단 네비 없음)

## 2. 인증 (Auth)

### 2.1 로그인 — `/auth/login`
| 상태 | 설명 | 와이어프레임 요소 |
|------|------|-------------------|
| **기본** | 이메일·비밀번호 입력 | 상단: [←] 뒤로가기. 타이틀 "로그인", 부제 "계정이 없으신가요? 회원가입" 링크. 필드: 이메일, 비밀번호. 버튼 "로그인" |
| **로딩** | 제출 중 | 동일 레이아웃, 버튼에 스피너 + "로그인 중..." |

### 2.2 회원가입 — `/auth/signup`
| 상태 | 설명 | 와이어프레임 요소 |
|------|------|-------------------|
| **기본** | 이름·이메일·비밀번호·비밀번호 확인 | 상단 [←]. 타이틀 "회원가입", "이미 계정이 있으신가요? 로그인" 링크. 필드: 이름, 이메일, 비밀번호, 비밀번호 확인. 버튼 "회원가입" |
| **에러** | 유효성/서버 에러 | 상단 폼 위에 빨간 배경 에러 박스 (예: "비밀번호가 일치하지 않습니다.") |
| **로딩** | 제출 중 | 버튼 "회원가입 중..." + 스피너 |
| **완료** | 가입 성공 후 | 전체 중앙: 체크 아이콘, "회원가입 완료", "잠시 후 메인 페이지로 이동합니다" |

## 3. 홈 — `/` (메인)

### 3.1 홈 — 비로그인
- **상단**: 우측 끝에 UserMenu(프로필) 영역만 (클릭 시 로그인 유도 등)
- **히어로**: 타이틀 "정비 견적, 적정 가격인지 바로 확인하세요" + 부제 "실제 정비 데이터로 견적을 검증·비교해드려요"
- **CTA 카드**: "견적서 촬영하기" (카메라 아이콘, "로그인 없이 바로 사용할 수 있어요") → `/verify/camera`
- **직접 입력** 버튼
- **로그인 유도 카드**: "로그인하면 검증 이력이 저장돼요" → `/auth/login`

### 3.2 홈 — 로그인 (차량 없음)
- 동일 구조 중: "OOO님, 견적서를 검증해볼까요?" 타이틀, CTA 카드 문구 "사진 한 장으로 적정 가격을 확인하세요"
- "내 차량" 카드 없음
- "최근 검증" 섹션 없음 (또는 빈 상태)

### 3.3 홈 — 로그인 (차량 있음)
- "내 차량" 미니 카드 1개: 제조사·모델·연식, [>] → `/vehicle`
- "최근 검증" 섹션: 최대 2건 리스트 (항목명, 날짜, 뱃지 적정/확인필요, 금액), "전체보기" → `/vehicle` (히스토리는 vehicle에서 링크)

## 4. 검증 플로우 (Verify)

### 4.1 검증 진입 — `/verify` → 리다이렉트 `/verify/camera`

### 4.2 견적서 촬영 — `/verify/camera`
| 상태 | 설명 | 와이어프레임 요소 |
|------|------|-------------------|
| **카메라 뷰** | 라이브 카메라 | 상단바: [플래시] [X]. 전체 화면 비디오. 코너 가이드(사각형 테두리). 하단 패널(흰색): 문구 "견적서 전체가 보이도록 촬영해주세요", 큰 원형 촬영 버튼, [앨범에서 선택] [직접 입력] |
| **카메라 로딩** | 카메라 준비 중 | 동일 레이아웃, 중앙 오버레이 "카메라 준비 중..." + 아이콘 |
| **카메라 에러** | 권한 거부 등 | 전체 검은 오버레이, 에러 메시지, [다시 시도] 버튼 |
| **촬영 완료** | 사진 확인 | 상단 [X]. 이미지 미리보기(전체). 하단 패널: "사진을 확인하고 다음 단계로 진행하세요", [재촬영] [자르기] [분석하기] |
| **품질 경고** | 흐림/어두움 등 | 모달: "사진을 조금만 더 선명하게 찍어볼까요?" 설명 + [다시 촬영하기] |

### 4.3 앨범에서 선택 — `/verify/album`
| 상태 | 설명 | 와이어프레임 요소 |
|------|------|-------------------|
| **선택 전** | 파일 선택 대기 | [←]. 타이틀 "앨범에서 선택", 부제 "견적서 사진을 선택해주세요". 카드 내부: 이미지 아이콘, "견적서 사진을 선택해주세요", "JPG, PNG · 최대 10MB", [사진 선택하기] |
| **에러** | 타입/크기 오류 | 상단 빨간 에러 박스 |
| **선택 후** | 미리보기 | 이미지 미리보기(비율 유지), 우상단 [X] 제거. 하단: [다시 선택] [자르기] [분석하기] |

### 4.4 직접 입력 — `/verify/manual`
| 상태 | 설명 | 와이어프레임 요소 |
|------|------|-------------------|
| **기본** | 차량+항목 입력 | [←]. 타이틀 "직접 입력", 부제. 카드 "차량": 저장된 내 차 있으면 "저장된 내 차 정보" 블록(이 차량으로 검증 / 다른 차량). 없으면 차량번호 입력 + [차량 정보 불러오기]. 정비 항목 리스트(빈 상태 또는 N건), [+ 항목 추가]. 하단 고정: 부품+공임, 부가세, 총 금액, [검증하기] |
| **항목 있음** | 리스트 + 하단 합계 | 동일, 항목 행(이름, 부품/공임, 금액) 탭 시 수정 바텀시트 |
| **바텀시트: 차량** | 차량 정보 수정 | 제목 "차량 정보 수정". 차량번호, [차량 정보 불러오기], 주행거리(km), [완료] |
| **바텀시트: 항목 추가/수정** | 항목 추가 또는 수정 | 항목명, 부품비, 공임비, 소계, [추가하기] 또는 [완료] (+ 수정 시 [삭제]) |
| **제출 중** | 검증하기 클릭 후 | [검증하기] → "저장 중..." + 스피너 |

### 4.5 견적 확인(리뷰) 위자드 — `/verify/review`
- **Step 1 (OCR 결과)**  
  - **성공**: 아이콘 + "견적서가 입력되었어요", "잠시만 기다려주세요..." (OCR 로딩 시 스피너)  
  - **실패**: "인식에 실패했어요" + 메시지, [다시 촬영하기], [직접 입력하기]
- **Step 2 (정비 정보)**: 헤더 "YYYY.MM.DD에 [정비소명]을 방문했어요". 카드: 방문일(탭→날짜 피커), 정비소(탭→검색 시트). 하단 [다음]
- **Step 3 (차량 정보)**: "어떤 차량의 견적서인가요?"  
  - 저장된 내 차 있음: "저장된 내 차 정보" 카드, [이 차량 선택] [다른 차량]  
  - 차량번호 입력: 입력 필드, [차량 조회]  
  - 조회 중: 스피너 "차량 정보를 조회하고 있어요..."  
  - 소유주 확인: 조회된 차량 요약, 소유주 이름 입력, [확인]  
  - 확정 후: 차량 요약 + "다른 차량으로 변경" 링크. 하단 [다음]
- **Step 4 (견적 목록)**: "견적 내역을 확인해주세요". 요약(방문일, 정비소, 차량). 정비 항목 리스트(N건), [+ 항목 추가]. 하단 고정: 총 금액, [견적 검증하기] (제출 중: "검증 중...")
- **공통 UI**: Step 2~4 상단 [←] + 스텝 인디케이터(점 3개). 데이트 피커 바텀시트(년/월/일 스크롤). 정비소 검색 시트. 항목 추가/수정 시트.

## 5. 검증 결과 — `/verify/result`·상세·가이드

### 5.1 검증 결과 목록 — `/verify/result`
| 상태 | 설명 | 와이어프레임 요소 |
|------|------|-------------------|
| **로딩** | 결과 조회 중 | 상단 [←]. 중앙 스켈레톤 또는 스피너 |
| **결과 있음** | 요약 + 항목 리스트 | 차량·정비소·총액, 전체 적정/확인필요 뱃지. 필터(전체/부품/공임/확인필요). 항목 카드 리스트(이름, 사용자 금액, 적정/확인필요, 평균 등). 하단 또는 상단: [공유], [저장]. 항목 탭 → `/verify/result/[itemId]` |
| **재검증** | 주행거리 수정 등 | 주행거리 수정 모달 등 (필요 시 별 프레임) |

### 5.2 항목 상세 — `/verify/result/[itemId]`
- [←] 뒤로가기. 항목명. 적정/확인필요 뱃지.
- 사용자 금액 vs 평균/범위 (차트 또는 숫자).
- 부품비·공임비 breakdown (펼치기/접기).
- 가이드 문구(있을 경우). "정비소에 물어보기" → `/verify/result/guide` 링크 등.

### 5.3 정비소 질문 가이드 — `/verify/result/guide`
- 확인필요 항목별 "질문 템플릿" 카드 (질문 문구, 설명, 복사 버튼).
- 뒤로가기, 필요 시 목록으로 돌아가기.

## 6. 내 차 — `/vehicle`·`/vehicle/edit`

### 6.1 내 차 — `/vehicle`
| 상태 | 설명 | 와이어프레임 요소 |
|------|------|-------------------|
| **비로그인** | 차량 미등록 유도 | 타이틀 "내 차량을 등록해보세요", "로그인하면 차량 정보와 정비 이력을 관리할 수 있어요" |
| **로그인, 차량 없음** | 등록 유도 | "차량을 등록해주세요", [등록 >] → `/vehicle/edit` |
| **로그인, 차량 있음** | 차량 요약 + 이력 | "제조사 모델 (variant)", "연식 · 주행거리 · 연료", [수정 >]. "총 정비 비용" 등 요약. "최근 검증" 리스트(날짜, 항목, 뱃지, 금액), [더보기] → 히스토리 등 |

### 6.2 차량 등록/수정 — `/vehicle/edit`
- [←]. 타이틀 "차량 등록" 또는 "차량 정보 수정".
- 차량번호 입력 + [차량 정보 불러오기]. 제조사·모델·연식·주행거리·연료 표시/수정.
- [저장] (로딩 상태: "저장 중...").

## 7. 검증 내역(히스토리) — `/history/[id]`

### 7.1 히스토리 상세 — `/history/[id]`
- 로그인 사용자만 접근. 없으면 404.
- 견적 요약(날짜, 정비소, 총액, 적정/확인필요).
- 항목 리스트. 항목 탭 시 상세(결과 페이지와 유사) 또는 인라인 펼침.

---

## 8. 더보기(설정) — `/settings`

### 8.1 설정 — 로딩
- 상단 "더보기", 스켈레톤(타이틀·카드 3개).

### 8.2 설정 — 비로그인
- "로그인해주세요", "검증 이력과 차량 정보를 관리할 수 있어요".
- 카드: [로그인/회원가입] (아이콘 + 설명).
- 기타 메뉴(이용약관, 개인정보처리방침 등).

### 8.3 설정 — 로그인
- "OOO님", 이메일.
- 알림: 토글 행 (정비 시기 알림, 검증 완료 알림, 마케팅 알림).
- 데이터: 내 차량 관리, 검증 이력 등 링크.
- [로그아웃] (로딩 시 "로그아웃 중...").

## 9. Figma 프레임 구성 제안

- **페이지 그룹**: `1.Auth`, `2.Home`, `3.Verify`, `4.Result`, `5.Vehicle`, `6.History`, `7.Settings`
- **프레임 네이밍**: `페이지명 / 상태명` (예: `홈 / 로그인(차량 있음)`, `촬영 / 촬영 완료`)
- **공통**: `공통 / 하단 네비`, `공통 / 뒤로가기 헤더`, `공통 / 로딩 스피너`
- **모바일 뷰포트**: 390×844 (iPhone 14 Pro) 등 1개 고정 후 복제해 상태별로 변경

이 명세대로 Figma에서 프레임을 만들고, 각 프레임에 위 표의 요소를 블록/텍스트/버튼으로 배치하면 와이어프레임이 완성됩니다.
