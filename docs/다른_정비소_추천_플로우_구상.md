# 다른 정비소 추천받기 플로우 구상

## 배경

- 검증 결과를 본 뒤, 또는 **정비사님께 질문**을 하고 나서도 사용자가 **다른 정비소를 추천받고 싶을 수** 있음.
- 현재는 검증 결과 하단에 "다른 정비소 추천받기" 버튼만 두고, 구체적인 플로우는 미정.

---

## 사용자 시나리오 정리

1. **검증 결과만 본 직후**  
   "이 견적 말고 다른 정비소도 비교해보고 싶다" → 다른 정비소 추천 요청

2. **항목 상세 → 정비사 질문까지 한 뒤**  
   "질문해봤는데 더 믿을 만한 다른 정비소를 알고 싶다" → 같은 버튼으로 다른 정비소 추천 요청

3. **저장 후 내 차 탭에서**  
   "저장된 견적과 다른 정비소 견적을 더 받고 싶다" → 내 차/검증이력 진입점에서도 추천 요청 가능성

---

## 플로우 옵션 (후보)

### A. 검증 결과 화면 내 단일 진입점

- **진입**: 검증 결과 페이지 하단 "다른 정비소 추천받기"만 유지.
- **이후**:  
  - (1) **지역·정비소 유형 선택** → 같은 차량/연식/주행거리·정비 항목을 전제로, 주변 또는 선택한 유형(블루핸즈/오토큐/일반 등) 정비소 목록 + 간단 정보(주소, 전화, 거리 등).  
  - (2) **"이 항목으로 다른 견적 받기"** 강조: 선택한 정비소에서 동일 항목 견적 받아오는 방법(전화 문의, 방문 등) 안내 또는 나중에 "견적 요청" 기능 연동.

- **장점**: 한 화면에서 끝나고, "검증 결과 보다가 → 바로 다른 정비소 찾기" 흐름이 명확.  
- **고려**: 항목 상세/질문까지 본 사용자도 같은 버튼으로 들어오므로, 화면 상단에 "이번 검증(차량·항목·지역) 기준으로 다른 정비소를 추천해 드립니다" 같은 문구로 맥락을 한 줄로 짚어주면 좋음.

### B. 항목 상세/질문 후 전용 CTA 추가

- **진입**: 항목 상세 하단 또는 "정비사님께 이렇게 질문해보세요!" 블록 아래에  
  **"다른 정비소도 비교해볼까요?"** → "다른 정비소 추천받기" 버튼 추가.
- **이후**: A와 동일하게 지역·유형 선택 → 추천 목록.

- **장점**: "질문까지 했는데 더 보고 싶다" 시점에 바로 유도 가능.  
- **고려**: 검증 결과 목록의 "다른 정비소 추천받기"와 동일한 목적지(추천 목록/필터 화면)로 보내면, 진입 경로만 다르고 경험은 통일 가능.

### C. "추천 목록"을 독립 화면으로

- **경로**:  
  - 검증 결과 하단 "다른 정비소 추천받기"  
  - (선택) 항목 상세 하단 "다른 정비소 추천받기"  
  → **공통**: `/recommend-shops` 같은 전용 라우트.
- **화면 구성**:  
  - 상단: 이번 검증 맥락 요약 (차량, 대표 항목 1~2개, 정비지역 등).  
  - 필터: 정비지역(시/도)·정비소 유형·거리(현재 위치 사용 시).  
  - 리스트: `national_repair_shops` 기반 카드 (이름, 주소, 전화, 유형, 거리).  
  - (선택) "이 정비소에서 견적 받기" 안내 또는 나중에 견적 요청/예약 연동.

- **장점**: 추천 로직·UI를 한 곳에 모아 확장하기 좋고, 공통 조건(지역·유형)을 재사용하기 쉬움.

---

## 데이터·기술 포인트

- **정비소 데이터**: `national_repair_shops` (주소, 시/도, 정비소 유형, 전화 등) 활용.
- **조건**:  
  - 이번 견적의 **정비지역(시/도)** 기본 적용 (이미 검증 결과에 노출 중).  
  - (선택) 사용자 위치(GPS 또는 입력 주소)로 거리 순 정렬.  
  - 정비소 유형(블루핸즈/오토큐/일반 등) 필터.
- **동일 항목 견적**: 현재는 "이 정비소에서 같은 항목 견적 받는 방법" 안내 수준으로 두고, 추후 API/제휴가 생기면 "견적 요청"으로 확장 가능.

---

## 제안 요약

- **단기**:  
  - 검증 결과 하단 "다른 정비소 추천받기"는 유지하고,  
  - 클릭 시 **"다른 정비소 추천" 전용 화면**(옵션 C)으로 이동하는 플로우를 기본으로 두기.  
  - 해당 화면에서 **이번 검증의 정비지역·차량/항목 맥락**을 한 줄로 보여주고, **지역(시/도)·정비소 유형** 필터 + `national_repair_shops` 기반 리스트만 먼저 구현.

- **중기**:  
  - 항목 상세/질문 블록 아래에 "다른 정비소 추천받기" 진입점 추가(옵션 B).  
  - 같은 추천 화면으로 연결해, "질문 후 다른 정비소 찾기" 시나리오를 만족.

- **장기**:  
  - 사용자 위치·거리 순 정렬, "이 정비소에서 견적 받기" 안내 또는 견적 요청 연동 검토.

이 구상대로 진행하면, "정비사님께 질문하고 나서도 다른 정비소를 추천받고 싶다"는 흐름을 한 버튼과 하나의 추천 화면으로 처리할 수 있음.
