# 자동차 365 공공데이터 활용 목적 (신청서 작성용)

---

## 데이터 활용 목적 (상세)

본인은 자동차 365(국토교통부·공공데이터포털)에서 제공하는 자동차종합정보 첨부형API를 아래와 같은 목적으로 활용하고자 합니다.

---

### 1. 활용 서비스 개요

서비스명(가칭): 자동차 정비 견적 검증 서비스

서비스 목적: 자동차 정비소에서 소비자가 받은 정비 견적서의 가격·항목이, 해당 차량 조건에서 적정 범위에 있는지 데이터 기반으로 검증하여 제공하는 서비스입니다.  
소비자가 “수리비 바가지(과다 청구) 불안”을 덜고, 견적서를 근거 있게 확인·검토할 수 있도록 지원하는 것이 목표입니다.

---

### 2. 제공받은 데이터의 활용 용도

자동차종합정보 첨부형API를 통해 제공받은 차량 정보(자동차등록번호 기반 조회 결과: 제조사, 차종, 연식, 연료종류, 제원 등)는 아래 용도로만 활용합니다.

| 활용 용도 | 구체적 내용 |
|-----------|--------------|
| 차량 정보 자동 입력 | 서비스 이용자가 본인 차량의 차량등록번호(번호판)를 입력하면, 자동차종합정보 첨부형API 조회 결과(제조사, 차종, 연식, 연료 등)를 활용하여 앱 내 “내 차 정보” 입력란을 자동으로 채우는 기능에 사용합니다. 이를 통해 사용자는 번호만 입력해도 차종·연식 등을 수동 입력하지 않고 편리하게 등록할 수 있습니다. |
| 견적 검증 시 조건 매칭 | 사용자가 정비소에서 받은 견적서를 촬영·입력하여 검증을 요청할 때, 해당 차량의 제조사·차종·연식·연료 등을 기준으로 “동일·유사 조건의 정비 사례” 또는 “표준 공임·부품 기준”과 비교합니다. 제공받은 차량 정보는 이 조건 매칭(클러스터링) 에 사용되어, “내 차와 비슷한 조건에서의 적정 가격 범위”를 산출하는 데 기여합니다. |
| 서비스 품질 및 UX 개선 | 차량 정보가 정확히 반영될수록 검증 결과의 신뢰도가 높아지므로, 잘못된 차종·연식 입력을 줄이고 사용자에게 더 정확한 비교 결과를 제공하기 위해 활용합니다. |

위 용도 이외에는 제공받은 데이터를 사용하지 않으며, 재제공·재판매·상업적 전용 등에는 사용하지 않습니다.

---

### 3. 데이터 처리 및 보안

- 조회 주체: 사용자가 “차량번호로 불러오기” 등을 통해 본인이 조회를 요청한 경우에만 자동차종합정보 첨부형API를 호출하며, 사용자 동의 절차를 거칩니다.
- 저장 범위: API 조회 시 사용한 차량등록번호·소유주명 등 개인식별정보는 저장하지 않고, 조회 결과 중 제조사, 차종, 연식, 연료 등 서비스 운영에 필요한 비식별화된 차량 속성만 저장·활용합니다.
- 제3자 제공: 제공받은 원본 데이터를 제3자에게 제공하거나 외부에 노출하지 않습니다.

---

### 4. 예상 이용자 및 서비스 형태

- 이용자: 자동차를 소유·이용하는 일반 소비자(개인)
- 서비스 형태: 웹/앱 기반의 정비 견적 검증 서비스 (견적서 촬영·입력 → 차량 정보 반영 → 유사 사례·표준 기준과 비교 → 적정 여부 및 가격 범위 안내)
- 데이터 사용 빈도: 사용자의 “차량 등록·수정” 또는 “견적 검증 시 차량 정보 조회” 요청 시에만 자동차종합정보 첨부형API를 호출하며, 불필요한 반복 조회를 줄이기 위해 캐시 등 절차를 적용할 예정입니다.

---

### 5. 요약 (한 문단)

자동차종합정보 첨부형API를 통해 제공받는 차량 정보는 “자동차 정비 견적 검증 서비스” 에서, (1) 이용자가 입력한 차량등록번호로 차량 정보(제조사·차종·연식·연료 등)를 자동 입력하고, (2) 견적 검증 시 동일·유사 차량 조건에 맞는 적정 가격 범위를 산출하기 위한 조건 매칭에 활용하며, (3) 잘못된 차량 정보 입력을 줄여 검증 결과의 신뢰도를 높이는 데 사용됩니다. 제공받은 데이터는 위 목적 외에는 사용·재제공하지 않으며, 개인식별정보는 저장하지 않고 비식별화된 차량 속성만 저장·활용할 예정입니다.
