# 블루핸즈/오토큐 WPC 부품비 정확 표시 및 가이드 사양

## 1. 배경

- **블루핸즈/오토큐**에서는 현대모비스 WPC(Warranty Parts Catalog)가 공개되어 있어, **차종·연식·부품 항목**으로 적용 부품이 거의 확정적이다.
- 따라서 이들 정비소 견적에 대해서는:
  - **부품비**를 “시장 평균”이 아니라 **WPC 순정 권장가(정확한 비용)**로 표시한다.
  - 부품비가 **과다**인 경우: “이 부품이 사용되었을 것”이라는 전제 + “가격이 다르다면 정비사님께 문의해보라”는 가이드 문구를 제공한다.

## 2. 데이터베이스 수정사항

| 구분 | 내용 |
|------|------|
| **테이블** | `item_verifications` |
| **추가 컬럼** | `part_price_source` `text` nullable |
| **허용 값** | `'wpc'` \| `'market'` (또는 null) |
| **의미** | `wpc`: 해당 항목 부품 기준가는 WPC 조회 결과(순정가). 블루핸즈/오토큐이고 WPC 매칭 시 저장. |
| | `market` 또는 null: 시장/FRT 등 참고 평균으로 표시. |

- **저장 시점**: 검증 결과 저장 시, 정비소가 블루핸즈/오토큐이고 해당 항목에 `breakdown.partCost.referencePrice`가 있으면 `part_price_source = 'wpc'`로 저장.
- **조회**: 검증 결과·항목별 검증 조회 시 `part_price_source` 포함하여 UI에서 “WPC 순정가” vs “시장 평균” 구분 표시에 사용.

## 3. UI/UX 수정사항

### 3.1 검증 결과 목록(카드)

- **부품비 라인** (부품비 > 0인 항목):
  - `part_price_source === 'wpc'`인 경우  
    → **“부품 00원 · WPC 순정가 00원 기준 (적정 / 기준 대비 ±N%)”** 형태로 표시.
  - 그 외  
    → 기존처럼 **“부품 00원 · 기준 대비 ±N% / 적정”** (기준 = 시장 평균).

### 3.2 검증 결과 상세(항목별)

- **부품비 섹션**:
  - `part_price_source === 'wpc'`:  
    **“WPC 순정가 00원”** 라벨로 표시하고, 사용자 부품비와 비교 (과다/적정/저렴).
  - 그 외:  
    **“시장 평균 00원”** 등 기존 표현 유지.
- **가격 분포**  
  - WPC인 경우 “순정 기준가” 한 점으로 해석 가능하다는 취지로, 필요 시 문구 보강 (선택).

### 3.3 가이드 문구 (부품비 과다 시)

- **대상**: 정비소가 **블루핸즈/오토큐**이고, 해당 항목 부품비가 **WPC 순정가 대비 과다**(`above_reference`)인 경우.
- **메시지**:
  - **부품 안내**:  
    “이 부품이 사용되었을 가능성이 높습니다. 가격이 다르다면 정비사님께 **부품번호 확인**을 요청해보세요.”
  - **정비사에게 이렇게 물어보세요** (askMechanicTip):  
    “이 항목에 적용된 부품번호가 무엇인지, 정비 명세서에 기재해 주실 수 있을까요?” 등 유사 문구 유지·보강.

- 일반 정비소/공임나라 등은 기존 가이드 유지.

## 4. 구현 흐름 요약

1. **DB**: `item_verifications.part_price_source` 컬럼 추가 (migration).
2. **검증 엔진**: 변경 없음. 이미 `breakdown.partCost.referencePrice`와 `shopType`을 사용 중.
3. **저장**: 검증 결과 저장 시 `shopType`이 블루핸즈/오토큐이고 `referencePrice`가 있으면 `part_price_source = 'wpc'`, 아니면 null 또는 `'market'` 저장.
4. **조회**: 항목별 검증 조회 시 `part_price_source` 포함.
5. **가이드**: `guide-messages.ts`에서 블루핸즈/오토큐 + `above_reference`일 때 위 문구로 통일.
6. **UI**: 결과 목록·상세에서 `part_price_source`에 따라 “WPC 순정가” vs “시장 평균” 라벨 및 문구 분기.
