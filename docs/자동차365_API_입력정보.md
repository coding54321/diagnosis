# 자동차 365 API — 차량정보 조회 시 필요한 입력 정보

자동차 365(국토교통부)·공공데이터포털에서 제공하는 **자동차종합정보 첨부형 API**로 차량정보를 조회할 때 필요한 입력 항목 정리.

---

## 1. 필수 입력 정보

| 입력 항목 | 설명 | 비고 |
|-----------|------|------|
| **차량등록번호** | 자동차 번호판에 적힌 등록번호 (예: 12가3456) | 필수 |
| **소유주명** | 해당 차량의 등록된 소유자 이름 | 필수 |

- **차량등록번호**와 **소유주명** 두 가지를 모두 입력해야 API 조회가 가능합니다.
- **소유주 동의 여부**에 따라 제공되는 항목이 달라집니다.
  - **동의한 경우**: 자동차 기본정보·제원·이력·성능점검 등 요청한 항목값을 넓게 제공받을 수 있습니다.
  - **미동의한 경우**: 소유주 미동의여도 받아올 수 있는 **제한된 항목**만 제공됩니다. (예: 제조사, 차종, 연식, 연료 등 비개인정보성 차량 정보 일부. 구체적인 항목 목록은 공공데이터포털·자동차365 이용가이드 참고.)
- 자동차365 포털에는 **타인차량조회(동의)** / **타인차량조회(미동의)** 메뉴가 구분되어 있어, 미동의 시에도 일부 조회가 가능한 구조입니다.

---

## 2. 제공받을 수 있는 정보 (조회 성공 시)

- 자동차 기본정보
- 제원정보
- 이력정보
- 성능점검정보  

→ 제조사, 차종, 연식, 연료종류, 제원 등으로 앱에서 “내 차 정보” 자동 입력·검증 조건 매칭에 활용 가능.

---

## 3. 현재 앱과의 차이

- **현재**: 차량등록번호만 입력하고 `vehicle_lookup_mock`(목업)으로 조회해 제조사·차종·연식·연료·주행거리 등을 채움.
- **실제 자동차 365 API 연동 시**:  
  - **차량등록번호** + **소유주명**을 함께 입력받아야 함.  
  - 소유주명 입력 필드(또는 동의 절차 시 이름 입력) 추가가 필요할 수 있음.  
  - 이용가이드·동의 절차는 [자동차365](https://www.car365.go.kr) 공지사항의 이용가이드 또는 [공공데이터포털 해당 API](https://www.data.go.kr/data/15071233/openapi.do) 참고.

---

## 4. 요약

- **차량등록번호 + 소유주명(이름)** 두 가지를 입력해야 조회할 수 있습니다.
- **소유주 미동의**여도 제한된 항목(비개인정보성 차량 정보 일부)은 받아올 수 있습니다. 동의 시 더 많은 항목을 제공받습니다.
- 미동의 시 제공 항목의 정확한 목록은 [공공데이터포털 해당 API 이용가이드](https://www.data.go.kr/data/15071233/openapi.do) 또는 [자동차365](https://www.car365.go.kr) 공지사항의 이용가이드에서 확인하는 것이 좋습니다.
