## Executive Summary

**문제의 본질**: 한국 자동차 정비 시장에서 소비자는 정비사의 진단에 전적으로 의존하면서 **"정말 이 비용이 맞나?"** 라는 불안을 겪는다. 이는 객관적 검증 수단의 부재로 인한 **정보 비대칭 문제**이다.  특히 자기 부담, 내부 진단 의존, 고가 견적, 의사결정 시점이라는 4가지 조건이 동시에 충족될 때 불안이 극대화된다.[1][2][3]

**기획 방향**: 사용자가 정비소에서 받은 견적서를 앱으로 입력하면, **유사 차량의 실제 정비 사례 데이터**와 즉시 비교하여 "정상 범위"를 통계적으로 제시함으로써 불안을 해소하는 솔루션이다. 현대/기아 오너의 265만명 기 확보된 **마이현대/마이기아 앱의 기능 추가**로 구현하면 시너지를 극대화할 수 있다.

**핵심 성공 요소**:

- 부품비 + 공임비의 **항목별 분리 분석**
- **통계적 정상 범위** 시각화 (중간값, 사분위수, 표본 수)
- **차량 조건 자동 매칭** (OCR + 차대번호 연동)
- **선택적 액션 가이드** (확인할 질문 리스트)

### 1.3 정보 비대칭의 근본 구조

정비 시장의 정보 비대칭은 **의료 시장과 동일한 구조**를 가진다.[5]

**❶ 기술적 정보 비대칭**

- 소비자: 부품의 역할, 고장 원인, 긴급도를 모름
- 정비사: 차량 상태, 필요한 작업, 부품 상태를 파악
- **결과**: 과잉 정비 여부 판단 불가능

**❷ 가격적 정보 비대칭**

- 소비자: 부품비/공임비의 적정 범위를 모름
- 시장: 동일 차종도 지점마다 가격 편차 큼[6]
- **결과**: "바가지" 불안 발생

### 1.4 불안 발생 메커니즘 (타겟 세분화)

**불안이 낮은 케이스** (문제 아님)

- **보험/보증 커버**: 자기 부담이 없어 비용 민감도 낮음
- **소모품/경정비**: 표준화된 작업, 대체 공급원 존재 (공임나라 등)
- **외장 수리**: 육안 확인 가능, 카닥 같은 대안 서비스 존재

**불안이 급등하는 임계점** (타겟 고객)
4가지 조건이 **모두 충족**될 때만 불안이 극대화:

1. **자기 부담** (보험/보증 아님)
2. **내부진단 의존** (정비사 진단으로 견적 결정)
3. **고가 인지** (심리적 저항선 초과)
4. **견적서 수령 직후** (의사결정 구간 - 약 30분)

**불안의 특징**: 고객은 "이 금액이 이상치인지" 판단하고 싶어 하는데, **정비사의 진단 근거**를 이해할 수 없어 불안이 **지속**된다.

```
억지로 돈을 낸다 (후회)
    ↓
이런 일이 반복된다 (신뢰 손실)

```

**디자인의 역할**은 3단계 (불신)에서 **"이건 정상이야"** 라는 근거를 제시하여 불안을 **확신**으로 바꾸는 것.

### 4.2 신뢰 구축의 핵심 원칙 (Price Comparison App 벤치마크)[16][17][18]

### 원칙 1: "정상 범위"를 통계로 명확하게 제시

❌ **하면 안 되는 것**

- "평균 12만 원입니다"만 제시
- 이유 설명 없음

✅ **해야 할 것**

```
브레이크 패드 교체 공임비
┌──────────────────────────────────┐
│ 당신의 견적: 15만 원              │
│ 이건 정상입니다 ✓                │
├──────────────────────────────────┤
│ 통계 데이터 (n=487)               │
│ 최소: 8만 원  ━━ 당신: 15만 ━━ 최대: 20만 원
│         ↑                      ↑
│      평균: 12만 원           10% 이상
│                            (비쌈)
│
│ 당신의 견적은 상위 30% 범위
│ (높지만 정상)
├──────────────────────────────────┤
│ 왜 이 정도인가?                    │
│ • 숙련도 높은 기술자 (레벨 3)      │
│ • 공식센터 + 보증포함             │
│ • 순정 부품 사용                   │
│ → 30% 프리미엄은 정상              │
└──────────────────────────────────┘

```

### 원칙 2: 비교 항목을 세분화 (부품비 vs 공임비)

많은 사용자의 불안은 "공임비"에서 발생한다.

```
총 비용: 51만 7천 원
├── 부품비: 55,000원 (명확함)
└── 공임비: 440,000원??? (불안)
    ├── 점검: 30분 (표준시간표)
    ├── 분해: 45분
    ├── 조립: 30분
    └── 시간당 60,000원 (블루핸즈 표준)
       = 105분 × 1000원/분 = 105,000원
       + 기술료: 335,000원 (왜?)

→ "기술료 335만원"이 불명확 → 불안

```

**개선 방안**:

```
공임비 명세
┌─────────────────────────┐
│ 작업시간: 105분 (표준) │
│ × 시간당 60,000원       │
│ = 기본공임: 105,000원   │
│                         │
│ 추가 기술료:            │
│ • 정밀진단료: 30,000원  │
│ • 특수공구료: 20,000원  │
│ • 부동액폐기료: 5,000원 │
│ = 소계: 55,000원        │
│                         │
│ 총 공임: 160,000원      │
└─────────────────────────┘

← 이렇게 하면 "335만원"의 의문이 해결됨

```

### 4.3 정보 배치 전략 (정보 계층)

**사용자가 원하는 정보의 순서**:

1. **한눈에 파악** (3초): "이게 정상인가?" YES/NO

3. **근거는?** (30초): 상세 데이터 + 비교 그래프
4. **의심이 있나?** (1-2분): 확인할 질문 리스트

## 부품/정비 특성 기반 정보 설계

### 6.1 자동차 부품의 특성 분류와 정보 배치 전략

자동차 정비는 크게 **소모품**, **구동 부품**, **외장/차체**, **전자장치** 등으로 나뉘며, 각각 사용자의 판단 난이도가 다르다.

### 유형 1: 소모품 정비 (낮은 불안도)

**특성**: 표준화됨, 주기적, 대체품 많음

| 항목 | 소비자 이해도 | 정보 필요성 | UI 전략 |
| --- | --- | --- | --- |
| 엔진오일 | 높음 | 낮음 | 간단 (수량, 규격만) |
| 에어필터 | 높음 | 낮음 | 사진 + 교체 사이클 |
| 배터리 | 높음 | 낮음 | 수명 안내 |
| 타이어 | 중간 | 중간 | 마모도 수치화 |
| 브레이크패드 | 중간 | 중간 | 마모도 + 안전성 |

**정보 배치 원칙**:

```
소모품은 표준화되어 있으므로
"평균 vs 당신" 비교만으로 충분
├─ 부품비 비교 (가격 투명성)
├─ 공임비 비교 (근로 비용)
└─ 주기 안내 (예방 정보)

```

**예시 UI**:

```
┌──────────────────────────────┐
│ 엔진오일 교체 (5W30, 4L)    │
│                              │
│ 부품비: 32,000원             │
│ 평균: 28,000 ~ 36,000       │
│ 당신: 정상 ✓                 │
│                              │
│ 공임비: 15,000원             │
│ 평균: 12,000 ~ 18,000       │
│ 당신: 정상 ✓                 │
│                              │
│ 다음 교체 주기: 1만km        │
│ 또는 6개월                   │
└──────────────────────────────┘

```

### 유형 2: 진단 의존 정비 (높은 불안도) ⚠️ **가장 중요**

**특성**: 정비사 판단 필요, 대체품 선택지 많음, 긴급도 모호

| 항목 | 원인 | 소비자 이해도 | 정보 필요성 |
| --- | --- | --- | --- |
| 변속기 문제 | 여러 가능성 | 매우 낮음 | 매우 높음 |
| 엔진 점화 불량 | 여러 부품 연관 | 매우 낮음 | 매우 높음 |
| 냉각수 누수 | 여러 위치 가능 | 낮음 | 높음 |
| 서스펜션 음성 | 원인 불명확 | 낮음 | 높음 |
| 경고등 (Check Engine) | 다양 | 매우 낮음 | 매우 높음 |

**정보 배치 원칙**:

```
진단 의존 정비에서는:
1) 진단 근거 제시 필수
   ├─ "왜 이 작업이 필요한가?"
   ├─ "지금 안 하면 뭐가 일어나나?"
   └─ "다른 선택지는 없나?"

2) 비용 범위 폭이 크다는 것을 인정
   ├─ 낮은 선택지 (OEM 부품)
   ├─ 중간 선택지 (호환 부품)
   └─ 높은 선택지 (고급 부품)

3) "의무 vs 선택" 구분
   ├─ 의무: 안전/법규 (하지 말아야)
   └─ 선택: 편의/성능 (연기 가능)

```

**예시 UI**:

```

- 좌측 하단 (낮은 이해 필요): 매우 간단

```

## 구현 로드맵

### Phase 1: MVP (최소 기능 제품) - 2025년 상반기

**범위**: 마이현대 앱 내 "견적 검증" 탭 추가

**필수 기능**:

1. **OCR 기반 견적서 입력** (네이버 CLOVA 또는 Naver Smart Lens)
2. **차량 자동 매칭** (마이현다 차량정보 연동)
3. **기본 통계 비교** (평균, 범위만)
4. **"정상/비정상" 판정**

**데이터**:

- 블루핸즈 과거 5년 데이터 (기존 보유)
- 표본: 상위 20개 정비소, 50만 건 이상

**개발 규모**: 4-6개월, 3-5명

### Phase 2: 강화 버전 - 2025년 하반기

**추가 기능**:

1. **상세 통계** (사분위수, 분포도)
2. **선택지별 비교** (OEM vs 호환 부품)
3. **정비사 신뢰도 연동** (블루핸즈 레벨 정보)
4. **확인 질문 자동 생성**
5. **정비 후 피드백 루프** (사후 검증)

**데이터 강화**:

- 사용자 업로드 데이터 수집 시작
- 타사 정비소 데이터 포함 (공정성)
- 표본: 100만 건 이상

**개발 규모**: 2-3개월, 팀 유지

### Phase 3: 고도화 - 2026년

**추가 기능**:

1. **AI 기반 과다청구 탐지** (이상 거래 탐지 패턴 적용)
2. **동네 정비소 비교** (지역별 가격 정보)
3. **영상 기반 진단** (손상도 AI 분석)
4. **정비 예약 연계** (예약 → 사전 검증)

**확장**:

- 비현대/KIA 차량 지원 (독립앱 고려)
- 해외 시장 확장 (일본, 중국)
