## 1. Executive Summary

### 1.1 원안의 강점

- 정보 비대칭으로 인한 **심리적 불안**을 핵심 페인포인트로 정확히 포착
- 자기부담 + 내부진단 + 고가 인지 + 견적서 수령 직후라는 **타겟 케이스 수렴이 정교함**
- 블루핸즈/오토큐 내부 데이터 활용 → 사용자 업로드 플라이휠이라는 **데이터 전략이 현실적**

### 1.2 개선이 필요한 영역

| 영역 | 원안의 Gap | 개선 방향 |
| --- | --- | --- |
| **도메인 특수성 반영** | 정비 유형별 견적 구조 차이 미반영 | 진단수리 vs 소모품 교체의 검증 로직 분리 |
| **정보 계층화** | "적정 범위" 제시만으로는 불안 해소 불충분 | 왜 이 가격인가에 대한 분해 설명 필요 |
| **사용 맥락 분리** | 현장용/사후검토용 플로우 미분화 | 맥락별 정보 밀도와 CTA 차별화 |
| **신뢰 구축** | 데이터 출처/신뢰도 표시 방안 부재 | 출처 명시, 표본 품질 지표 도입 |
| **정비사 관점** | 사용자 vs 정비사 갈등 구도로 흐를 위험 | 정비사도 활용 가능한 설명 도구화 |

### 1.3 핵심 개선 원칙

```
"가격이 비싼지 싼지"를 알려주는 것이 아니라,
"왜 이 가격이 나왔는지"를 이해시켜 불안을 해소한다.

```

## 2. 도메인 분석: 자동차 정비의 특수성

### 2.1 정비 유형별 견적 구조의 차이

자동차 정비는 크게 **표준화 정비**와 **진단 의존 정비**로 나뉘며, 각각 견적 구조와 가격 변동 요인이 완전히 다릅니다.

### 2.1.1 표준화 정비 (Predictable Maintenance)

| 특성 | 내용 |
| --- | --- |
| **예시** | 엔진오일 교환, 에어컨 필터 교환, 브레이크 패드 교체, 타이어 교체 |
| **견적 구조** | 부품비(고정) + 공임비(표준공임 적용) |
| **가격 변동 요인** | 부품 등급(순정/OEM/애프터마켓), 지역, 정비소 유형 |
| **검증 난이도** | 낮음 - 항목명만으로 비교 가능 |
| **기존 대안** | 공임나라, 네이버 검색으로 어느 정도 가격 파악 가능 |

### 2.1.2 진단 의존 정비 (Diagnosis-Dependent Repair)

| 특성 | 내용 |
| --- | --- |
| **예시** | 엔진 이상음 수리, 변속기 문제, 전장 계통 고장, 냉각수 누수 |
| **견적 구조** | 진단비 + 부품비(다수) + 공임비(작업시간 기반) + 추가 발견 항목 |
| **가격 변동 요인** | 고장 범위, 연관 부품 손상 여부, 작업 난이도, 정비사 숙련도 |
| **검증 난이도** | 높음 - 동일 증상이라도 원인과 수리 범위가 천차만별 |
| **기존 대안** | 사실상 없음 (본 서비스의 핵심 타겟) |

### 2.2 블루핸즈/오토큐/하이테크센터 운영 실정

### 2.2.1 공임 산정 체계

현대/기아 공식 서비스센터는 **표준정비시간(Flat Rate Time)** 기반으로 공임을 산정합니다.

```
공임비 = 표준정비시간(시간) × 시간당 공임(원/시간)

```

- **표준정비시간**: 현대/기아 본사에서 작업별로 규정 (예: 브레이크 패드 교체 0.5시간)
- **시간당 공임**: 센터 유형/지역에 따라 상이
    - 블루핸즈: 약 45,000~55,000원/시간
    - 오토큐: 약 50,000~60,000원/시간
    - 하이테크센터: 약 65,000~80,000원/시간

### 2.2.2 실제 견적서 구성 항목

블루핸즈 견적서의 일반적 구성:

```
┌─────────────────────────────────────────────────────────┐
│  현대자동차 블루핸즈 [지점명]                              │
├─────────────────────────────────────────────────────────┤
│  차량정보: 투싼 NX4 2022년식 / 주행거리 45,000km          │
├─────────────────────────────────────────────────────────┤
│  [정비 항목]                                              │
│  ─────────────────────────────────────────────────────   │
│  1. 브레이크 패드 교체(전륜)                               │
│     - 부품비: 순정부품 XXXX-XXXXX × 2  │  120,000원      │
│     - 공임비: 0.8H × 50,000원         │   40,000원      │
│                                        소계: 160,000원   │
│  ─────────────────────────────────────────────────────   │
│  2. 브레이크 디스크 연마(전륜)                             │
│     - 공임비: 0.5H × 50,000원         │   25,000원      │
│                                        소계:  25,000원   │
├─────────────────────────────────────────────────────────┤
│  부품비 합계:  120,000원                                  │
│  공임비 합계:   65,000원                                  │
│  부가세:        18,500원                                  │
│  ─────────────────────────────────────────────────────   │
│  총 청구금액:  203,500원                                  │
└─────────────────────────────────────────────────────────┘

```

### 2.2.3 가격 변동이 발생하는 지점

| 변동 지점 | 설명 | 합리적 범위 |
| --- | --- | --- |
| **부품 등급** | 순정 vs OEM vs 애프터마켓 | 순정 대비 OEM 70~80%, 애프터 50~60% |
| **시간당 공임** | 센터 유형/지역에 따라 상이 | 지역별 ±20% 내외 |
| **작업시간 할증** | 녹/고착/특수차량 등 추가 시간 | 표준시간의 1.2~1.5배 |
| **추가 발견 항목** | 점검 중 발견된 문제 | 별도 항목으로 분리 필요 |
| **소모품 동시 교체** | 가스켓, 볼트, 클립 등 | 통상 1~3만원 범위 |

### 2.3 정비 항목 분류 체계 (Taxonomy)

서비스 내에서 사용할 표준 분류 체계를 정의합니다. 이는 OCR 결과 매핑, 유사 사례 검색, 데이터 집계의 기반이 됩니다.

```
├── 엔진 계통
│   ├── 엔진 본체
│   ├── 흡배기 계통
│   ├── 연료 계통
│   └── 냉각 계통
├── 변속기 계통
│   ├── 수동변속기
│   ├── 자동변속기
│   └── DCT/CVT
├── 구동/조향 계통
│   ├── 조향장치
│   ├── 현가장치
│   └── 구동축/허브
├── 제동 계통
│   ├── 디스크/패드
│   ├── 캘리퍼/라인
│   └── ABS/ESC
├── 전기/전장 계통
│   ├── 시동/충전

│   └── 편의장치
├── 외장/차체
│   ├── 도장/판금
│   ├── 유리/썬루프
│   └── 범퍼/몰딩
└── 정기 점검/소모품
    ├── 오일류

    └── 기타 소모품

```

### 2.3.2 2차 분류: 작업 유형별

| 작업 유형 | 코드 | 특성 |
| --- | --- | --- |

## 3. 정보 비대칭 해소를 위한 핵심 전략

### 3.1 불안의 구조 분해

사용자 불안을 세분화하면 아래와 같이 3가지 층위로 나눌 수 있습니다:

```
┌─────────────────────────────────────────────────────────┐
│  Layer 3: 가격 불안                                      │
│  "이 금액이 정상인가?"                                    │
├─────────────────────────────────────────────────────────┤
│  Layer 2: 범위 불안                                      │
│  "이 항목들이 다 필요한 건가?"                            │
├─────────────────────────────────────────────────────────┤
│  Layer 1: 이해 불안                                      │
│  "무슨 말인지 모르겠다"                                   │
└─────────────────────────────────────────────────────────┘

```

**핵심 인사이트**: 원안은 Layer 3(가격 불안)에 집중했으나, Layer 1, 2가 해소되지 않으면 가격 정보만으로는 불안이 완전히 해소되지 않습니다.

### 3.2 층위별 해소 전략

### Layer 1 해소: 이해 불안 → "설명 번역"

| 요소 | 전략 |
| --- | --- |
| **전문용어 번역** | "인젝터 클리닝" → "연료 분사 노즐 세척 (연비 개선 효과)" |
| **부품 역할 설명** | 해당 부품이 어디에 있고, 무슨 역할을 하는지 시각화 |
| **증상-원인 연결** | "시동 시 덜덜거림 → 점화플러그 마모 가능성" |

### Layer 2 해소: 범위 불안 → "필수/권장/선택 분류"

| 분류 | 기준 | UI 표현 |
| --- | --- | --- |
| **필수(Must)** | 안전/주행 불가 관련, 즉시 조치 필요 | 🔴 빨간색 강조 |
| **권장(Should)** | 방치 시 악화, 1개월 내 권장 | 🟡 노란색 |
| **선택(Could)** | 예방 정비, 편의 개선 | 🟢 초록색 |

**데이터 기반 분류 로직**:

- 현대/기아 정비 매뉴얼의 점검 주기/교체 주기 데이터 활용
- 주행거리, 연식, 이전 정비 이력 기반 개인화

### Layer 3 해소: 가격 불안 → "분해 + 비교"

```
[기존 원안]
"브레이크 패드 교체: 내 견적 15만 원 – 동일차종 평균 12만 원"

[개선안]
"브레이크 패드 교체: 160,000원"
├── 부품비: 120,000원 (순정)
│   └── 비교: OEM 대체 시 약 85,000원 (-35,000원)
├── 공임비: 40,000원 (0.8시간 × 50,000원)
│   └── 표준정비시간 기준 적정
└── 유사 사례 범위: 130,000원 ~ 180,000원 (중앙값 155,000원)
    └── 현재 견적: 적정 범위 내 ✓

```

### 3.3 "적정 범위" 표현의 재설계

원안의 "통계적 정상 범위" 표현은 정확하지만, 사용자 입장에서 "그래서 비싼 건가, 아닌 건가"가 직관적이지 않습니다.

### 개선: 5단계 판정 체계

| 판정 | 범위 | 표현 | 컬러 |
| --- | --- | --- | --- |
| **매우 저렴** | 하위 10% 미만 | "평균보다 저렴해요" | 🔵 Blue |
| **적정** | 하위 10% ~ 상위 20% | "적정 범위예요" | 🟢 Green |
| **다소 높음** | 상위 20% ~ 상위 10% | "평균보다 높은 편이에요" | 🟡 Yellow |
| **높음** | 상위 10% ~ 상위 5% | "확인이 필요해요" | 🟠 Orange |
| **매우 높음** | 상위 5% 초과 | "재확인을 권장해요" | 🔴 Red |

### 시각화: 분포 차트 + 내 위치

```
                    ▼ 내 견적: 160,000원
    ┌────────────────────────────────────────────┐
    │░░░░░░░░░░░████████████████████░░░░░░░░░░░░│
    └────────────────────────────────────────────┘
    10만        13만      15.5만(중앙)    18만     22만

    "적정 범위입니다" ✓

    [비슷한 차량 50건의 실제 정비 비용 기준]

```

## 4. 정보 계층 구조 설계

### 4.1 Progressive Disclosure 원칙

정비 도메인은 정보량이 많아, 한 번에 모든 정보를 보여주면 오히려 혼란을 야기합니다. **단계적 정보 공개(Progressive Disclosure)** 원칙을 적용합니다.

```
[1단계: 요약] ─────────────────────────────────────────────
  "총 203,500원 - 적정 범위입니다 ✓"

[2단계: 항목별] ────────────────────────────────────────────
  ├── 브레이크 패드 교체: 160,000원 - 적정 ✓
  └── 디스크 연마: 25,000원 - 적정 ✓

[3단계: 상세 분해] ─────────────────────────────────────────
  브레이크 패드 교체
  ├── 부품비: 120,000원 (순정, 표준가 기준 적정)
  ├── 공임비: 40,000원 (0.8시간, 표준시간 내)
  └── 대안: OEM 부품 시 약 35,000원 절감 가능

[4단계: 근거 데이터] ────────────────────────────────────────
  ├── 비교 데이터: 동일 차종/연식 50건
```

## 5. 유저 플로우 상세 설계

### 5.1 사용 맥락별 플로우 분리

### 맥락 A: 현장 검증 (Primary Use Case)

**상황**: 정비소에서 견적을 받고, 수리 진행 여부를 결정해야 하는 순간

**핵심 니즈**: 빠른 판단, 명확한 결론, 정비사에게 질문할 포인트

**시간 제약**: 3~5분 이내에 핵심 정보 파악 필요

### 맥락 B: 사후 검토 (Secondary Use Case)

**상황**: 이미 수리를 마쳤거나, 집에서 천천히 견적을 검토하는 상황

**핵심 니즈**: 상세 분석, 학습, 향후 참고 자료 저장

**시간 제약**: 없음, 깊이 있는 정보 탐색 가능

## 부록 C: 정비사 관점의 서비스 활용

### C.1 정비사도 활용할 수 있는 설명 도구

이 서비스는 정비사와 고객 간의 **커뮤니케이션 도구**로도 기능할 수 있습니다.

### 활용 시나리오

```
[고객이 견적에 의문을 제기할 때]

정비사: "저희 견적을 앱으로 확인해보시겠어요?
         비슷한 차량의 실제 정비 비용 데이터와 비교해볼 수 있어요."

→ 앱에서 "적정 범위" 판정이 나오면
   고객의 의심 해소 + 정비사의 설명 부담 감소

→ "다소 높음" 판정이 나오면
   정비사가 추가 설명 기회 (부품 등급, 작업 난이도 등)

```

### 정비사 관점의 이점

| 이점 | 내용 |
| --- | --- |
| **설명 부담 감소** | 데이터 기반 근거 제시로 고객 설득 용이 |
| **신뢰 구축** | "투명하게 공개해도 문제없다"는 신뢰 형성 |
| **분쟁 예방** | 사후 "바가지" 클레임 감소 |

### C.2 정비소 제휴 프로그램 (향후)

- "견적 투명성 인증 정비소" 배지 부여
- 앱 내 정비소 추천 시 우선 노출
- 정비소 자체 견적 사전 검증 도구 제공
